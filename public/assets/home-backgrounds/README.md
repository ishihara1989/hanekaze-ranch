# トップページの四季背景

内蔵 `image_gen` で春の牧場を生成し、同じ画像を季節ごとに編集して制作。
建物・柵・道・山の構図をそろえた、シロマの立ち絵用の背景です。
全画像 1536 × 1024 px、不透明 WebP（品質90）。元PNGは生成画像の保存先に保持しています。

| ファイル | ゲーム内の季節 |
|---|---|
| spring-v1.webp | 春：3〜5月、桜と若草 |
| summer-v1.webp | 夏：6〜8月、緑と青空 |
| autumn-v1.webp | 秋：9〜11月、紅葉と落ち葉 |
| winter-v1.webp | 冬：12〜2月、雪景色 |

`public/js/ranch-ui.js` でゲーム内の月を読み、ヘッダーの季節と背景を同じ定義で切り替えます。
`object-fit: cover` で表示枠に合わせ、シロマと会話パネルは既存のレイヤーで重ねます。
生成プロンプト全文は `prompts-v1.json` に記録しています。
`preview.html` で四季の画像とシロマを重ねた表示を確認できます。セーブデータには触れません。
