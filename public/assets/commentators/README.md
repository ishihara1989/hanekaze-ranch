# レースの実況席

内蔵 image_gen により生成した透過PNG。

- `lamia.png`：ラミア（実況）。全身画像から腰の少し下で切り出した上半身の構図。金髪、額の赤い宝石、自然に下へ続く赤〜ピンクの蛇体、紫の衣装、ヘッドセット、実況中の表情。
- `lamia-full.png`：1024×1536の縦長の全身原画。腰から尾先まで1本につながる蛇体を自然な長さで描き、再トリミング用に保存。
- `sahagin.png`：サハギン（解説）。顔・肩・胸元のバストアップ。鋭く細い目、太った青い魚体、白い胸、黄色い厚い口元、青白いヒレ、ヘッドセット。
- `prompts.json`：各画像を生成した最終プロンプトとラミアのトリミング範囲。

原作の参考画像をもとに外見を調整し、実況用のヘッドセットと既存のイラストのタッチを維持。

ラミアは全身原画の `(x=32, y=0, 幅=992, 高さ=906)` を切り出し。画像の変形・縮尺変更なしで透過を維持し、尾は画面外へ自然に続く構図とした。

3D観戦画面の実況席で表示し、発話担当を明るくする。
