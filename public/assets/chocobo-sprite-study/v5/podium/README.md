# 表彰台・声援への挨拶

正面寄りの待機から少し右を向き、くちばしをわずかに開いて画面右側の羽を上げる。羽を下ろして正面へ戻り、左右反転した左側への挨拶へ続く。足は接地したまま、全コマで足元を揃えている。

- 448×448の8コマ、4列×2行、1792×896の透過PNG。
- 原画は右側への動き4コマ。5〜8コマは1〜4コマのRGBAを完全に左右反転したもの。
- 本体10色・額羽6色を同じコマ・座標・倍率で重ねる。60通りに対応し、両レイヤーのアルファは重複しない。
- 額羽の輪郭と全羽色のアルファは共通。くちばし、目、裸の脚、足、爪は本体色を変えても共通。
- 金色は原画の羽領域へ、生成した金属光沢のRGBだけを取り込む。
- `manifest.json` の `frameSequence` を5fpsで再生すると3.2秒ループ。待機と羽を上げた挨拶を各0.6秒、移行を各0.2秒保持する。
- `anchor` は足元の座標。表彰時はコースの進行方向による追加反転をせず、シート内の左右をそのまま使う。
- `preview-poses.png` は待機・右への挨拶・左への挨拶の一覧。

内蔵 `image_gen` で原画、領域マスク、金色の質感を作成。プロンプト全文は [PROMPTS-podium-v1.json](../../PROMPTS-podium-v1.json)。切り出し・位置合わせ・色差分・反転はビルドツールで再現できる。

再構築: `node tools/build_chocobo_podium.cjs`

検査: `node tools/validate_chocobo_podium.cjs`（透過境界、色差分、固定部位、全レイヤーの左右反転、足元、余白）。結果は `output/imagegen/sprite-podium-v1-validation.json`。

プレビュー: `/chocobo-sprite-preview.html?motion=podium`。本体と額羽の個別確認、全色差分、コマ送りに対応。2Dレースの優勝時の表彰台でも再生する。
