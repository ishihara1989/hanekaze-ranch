# 2D走行スプライト・試作02

修正した同一の8コマから、本体10色と額羽6色を独立した透過シートとして作成した。合計16枚を重ね、60通りの羽色・額羽を表現する。

## プレビュー

`http://127.0.0.1:4184/chocobo-sprite-preview.html`。通常の起動では `node server.cjs` とポート4173を使う。
羽色・額羽の選択、全10体色の同期再生、額羽6色の拡大表示、本体のみ・額羽のみの確認、コマ送り、表示サイズ、背景切替に対応。
本体PNG・額羽PNGのリンクは選択中のレイヤーを開く。

## 脚の修正

カメラに近い明るい橙の脚を左脚、奥の暗い茶橙の脚を右脚として固定した。

| コマ | 動き |
| --- | --- |
| 1 | 右脚が前で着地、左脚は後ろ |
| 2 | 右脚が体の下で荷重、左脚を回収 |
| 3 | 右脚が後ろで蹴り、左脚を前へ |
| 4 | 浮遊、左脚を前へ伸ばす |
| 5 | 左脚が前で着地、右脚は後ろ |
| 6 | 左脚が体の下で荷重、右脚を回収 |
| 7 | 左脚が後ろで蹴り、右脚を前へ |
| 8 | 浮遊、右脚を前へ伸ばし1へ戻る |

前半と後半で同じ脚を繰り返していた初版を修正した。上半身の絵柄は維持しているが、8コマの形の小さな揺れや接地・浮遊のタイミングは、引き続き制作上の調整対象。

## 素材

`manifest.json` に全素材のファイル名、色の日本語ラベル、コマの仕様と動作ラベルを収録。

- `body-{yellow,red,blue,green,rose,white,black,purple,gray,golden}.png`: 本体10枚。くちばし・目・裸の脚・爪を含み、額羽を除く。
- `crest-{yellow,red,blue,white,black,rainbow}.png`: 額羽だけの透過差分6枚。走行中のコマごとの位置を含む。
- `body-mask.png` / `crest-mask.png`: 対応する色領域の透過マスク。
- 1階層上の `run-yellow-v2.png`: 組み込み画像生成で脚を修正した元画像。
- 1階層上の `regions-v2.png`: 組み込み画像生成で作った部位識別画像。本体はシアン、額羽はマゼンタ、非着色部は黒。
- 1階層上の `PROMPTS-v2.md`: 実際に使った編集プロンプト。

生成された1774×887の元画像をコマ単位で整数座標に分け、拡縮せず448×448のセルに余白を加えた。全レイヤーは1792×896、4列×2行、RGBA。
アルファ16未満の微細な画素と部位識別から離れた微細な画素は整理した。

## 合成する

`frame` は0〜7。切り出し位置は `x = (frame % 4) * 448`、`y = Math.floor(frame / 4) * 448`。
同じ切り出し矩形・表示座標・倍率で本体を描き、その上に額羽を描く。追加の個体別位置合わせは不要。
プレビューの実装は `public/js/chocobo-sprite-preview.js`。

## 色と輪郭

色の展開は画像を個別に再生成せず、同じ部位マスクと元の明暗から`../palette.json` の共通色表へ変換した。
全体色で輪郭・脚の動き・額羽の位置が一致する。目の色は元の緑を維持している。
虹の額羽は付け根から先端へ色が移り、元の羽の陰影を保つ。

再構築はリポジトリ直下で `node tools/build_chocobo_sprites.cjs`。PNGの読み書きにpngjsを使い、通常のNode依存またはCodexの同梱ランタイムから探索する。

検査では、本体10色のアルファ一致、額羽6色のアルファ一致、本体と額羽の非重複、104,919画素の固定領域（くちばし・目・裸の脚・爪など）の色の維持を確認した。
レポートは `output/imagegen/sprite-v2-validation.json`。
本体と額羽の色境界は生成された識別画像に依存するため、拡大時の細かい境界の仕上げは今後の調整対象。
