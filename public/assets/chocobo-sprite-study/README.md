# チョコボ 2D走行スプライト試作 01

現在のプレビューは試作05。完成した試作04のモーションを維持し、金色だけに白金色の反射と深い陰影を追加した。本体10色・額羽6色の独立レイヤーで60通りを表現する。[試作05の仕様と素材](v5/README.md)を参照。以下は初版の検証記録。

2026-10-02。右向き・少し上からの横構図を、2Dの彩色スプライトで試した独立プレビュー。

## 見る

`node server.cjs` を起動し、`http://127.0.0.1:4173/chocobo-sprite-preview.html` を開く。
作成時のプレビューは既存サーバーとの競合を避けてポート4184で起動。

- `run-yellow.png`: 黄の体 × 黄の額羽（基準）。
- `run-blue.png`: 体だけを青に変更、額羽は黄。
- `run-rainbow-crest.png`: 黄の体を維持し、額羽だけを虹色に変更。
- `PROMPTS.md`: 使用した全プロンプトと修正内容。

各画像は1774×887ピクセル、RGBA、4列×2行の8コマ。背景には実際の透過アルファがある。
画像生成側は指定した2048×1024ではなくこの寸法を返したため、プレビューは画像の実寸を4列×2行に分けてCanvasで再生する。コマ境界の寸法は443.5ピクセルとなるため、制作時に整数サイズのセルへ整理する必要がある。
プレビューは再生・停止、4〜20fps、約96／144／216pxの表示、背景変更、コマ送りに対応する。大きな表示はカードの横幅に合わせて縮小する。

## この試作で確認できたこと

- 青の体と黄色い額羽を同時に表現できた。
- 虹の額羽と黄色い体を同時に表現できた。最初の生成では1コマの尾にも虹色が漏れ、局所編集で修正した。
- 約96pxの縮小表示でも、体色と額羽の大きな色差は視認できた。全10体色×6額羽の組み合わせは未検証。
- 見た目はほぼ横からの構図。背・羽の上面が少し見えるが、より強い俯角やカーブ用の方向差分は未検証。

## 本採用前に直すこと

- 8コマには似た脚位の繰り返しがあり、左右の脚の交互接地が十分に整理されていない。自然な走行周期と接地を作り直す。
- コマごとに頭・尾・輪郭・位置に小さな揺れがあり、差分画像も完全な同一輪郭ではない。
- 読み取り検査で、アルファ100超を輪郭とした基準シートとのIoUは青0.93726、虹0.91940。これはシート全体の輪郭一致の目安で、画質やモーション品質の点数ではない。
- 量産時には本体と額羽の独立した領域マスク、必要なら額羽レイヤーを設け、ゲーム側の色変更で輪郭とポーズを維持する方法を検討する。現在のPNGはフラットな合成画像で、分離マスクはまだ作っていない。
- 輪郭付近の微細な半透明画素を整理し、整数セル・共通基準点・全コマの余白を決める。

生成には組み込みの`image_gen`ツールを使用。モデル選択パラメーターがないため、Imagen 2.5を使用したとの確認はできない。
レース画面の描画・遺伝のデータやロジックは変更していない。サーバーにはこの独立ページと3画像の配信経路だけを追加した。


## 共通の色表

走行・歩行・スパート・表彰スプライトの再生成には `palette.json` の本体10色と額羽6色を使います。色表は2D素材と一緒に管理し、3Dモデルには依存しません。
