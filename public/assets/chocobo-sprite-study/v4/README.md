# 2D走行スプライト・試作04

4コマ目の手前の明るい太ももを、5コマ目と同様に前へ出る形へ修正。前へ伸ばした橙色の脚とのつながりを保った。
修正対象は4コマ目の太もも。生成編集に伴い、他の部位にも微細な描き直しはある。

プレビュー: `http://127.0.0.1:4184/chocobo-sprite-preview.html`。
4・5コマ目を固定して並べ、前に出た太もものつながりを比較できる。再生・コマ送り・色の切り替えにも対応。

## 素材

- `manifest.json`: 全素材名、色名、8コマの仕様と説明。
- `body-*.png`: 本体10色。額羽を除き、目・くちばし・裸の脚・爪を含む。
- `crest-*.png`: 額羽6色の透過差分。本体と同じ位置・コマ・倍率で重ねる。
- `body-mask.png` / `crest-mask.png`: 着色領域。
- 1階層上の `run-yellow-v4.png`: 修正版の黄色の原画。
- 1階層上の `regions-v4.png`: 原画に対応する部位識別画像。
- 1階層上の `PROMPTS-v4.md`: 使用した編集・マスク生成プロンプト。

全レイヤーは1792×896、4列×2行、448×448の8コマ。原画から拡縮せず切り出し、余白を追加して整数セルに整理した。
本体10枚＋額羽6枚で全60通りに対応する。全色を同じ原画から変換するため、色を変えてもモーション・輪郭の位置は揃う。

再構築: `node tools/build_chocobo_sprites.cjs`（既定は版4）。引数 `2` / `3` で以前の版も再構築できる。
アルファ・非着色領域の検査結果: `output/imagegen/sprite-v4-validation.json`。
以前の版3は `v3/` とその原画・部位識別画像に保存している。
