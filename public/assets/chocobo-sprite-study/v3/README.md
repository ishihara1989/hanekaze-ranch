# 2D走行スプライト・試作03

太ももの羽毛と、その下につながる裸の脚を一組として動かす修正版。試作02の羽色10色・額羽6色の独立レイヤー方式を維持した。

## 今回の修正

- 手前の明るい羽毛と橙色の脚、奥の陰になった羽毛と暗い茶色の脚を、それぞれつながる一つの脚として整理。
- 4コマ目では手前の羽毛の塊を前へ傾け、前へ伸ばした橙色の脚につなげる。
- 8コマ目では手前の羽毛の塊を後ろへ傾け、後ろへ折りたたんだ橙色の脚につなげる。
- 他のコマも同じ対応に揃え、前半・後半の接地と回収の順序を維持。上半身の絵柄を引き継いだが、生成編集による細部の描き直しはある。
- 左右の解釈に依存せず確認できるよう、画面の説明は「手前／奥」にした。1〜4コマは奥の暗い脚、5〜8コマは手前の明るい脚が接地・蹴り出しを担当する。

## 確認する

現在のプレビュー: `http://127.0.0.1:4184/chocobo-sprite-preview.html`。
通常はリポジトリ直下で `node server.cjs` を起動し、ポート4173で同じページを開く。
再生・コマ送り・全色の組み合わせに加え、「太ももと脚のつながり」で4・8コマ目を固定して並べた。固定比較も選択中の羽色・額羽を反映する。

## 素材と合成

- `manifest.json`: 全素材のファイル名、色名、コマ仕様、各コマの説明。
- `body-*.png`: 額羽を分離した本体10色。くちばし、目、裸の脚と爪を含む。
- `crest-*.png`: 額羽だけの透過差分6色。
- `body-mask.png` / `crest-mask.png`: 色領域のマスク。
- 1階層上の `run-yellow-v3.png`: 修正した黄色の元画像。
- 1階層上の `regions-v3.png`: 修正版に対応する部位識別画像。
- 1階層上の `PROMPTS-v3.md`: 実際に使用した全編集プロンプト。

全レイヤーは1792×896、4列×2行、448×448の8コマ。拡縮せず元画像から切り出し、整数サイズのセルに余白を追加した。
本体と額羽を同じコマ・座標・倍率で描く。本体10枚＋額羽6枚で全60通りに対応する。
全色は同じ原画から明暗を保って色変換するため、太もも・脚・輪郭の位置は色によって変化しない。
再構築は `node tools/build_chocobo_sprites.cjs`（既定は版3）。`node tools/build_chocobo_sprites.cjs 2` は以前の版2を再構築する。

アルファと非着色領域の検査結果は `output/imagegen/sprite-v3-validation.json`。
プレビューで4・8コマ目のつながりを確認し、元シート全8コマの手前・奥の対応も目視した。細かなコマ間の形の変化、接地のタイミング、色境界は引き続き仕上げの対象。
