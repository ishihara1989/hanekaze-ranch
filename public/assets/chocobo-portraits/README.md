# 一覧・ステータス用の年齢別スプライト

## 現行: 4コマ待機スプライト v3

組み込み `image_gen` で生成した透過PNG（1254×1254、2列×2行）。
ヒナ・幼羽は1コマ627×627。成羽は尾先を収めるため実際の列間の余白（x=660）で切り出す。
表示時に左右反転し、正面やや左向きにそろえる。
左上→右上→左下→右下の順に呼吸をループする。
走行の `run-yellow-v4.png` と表彰の `podium-yellow-v1.png` を直接参照し、
濃い輪郭線、大きく尖った羽、はっきりした陰影、緑の目、橙赤のくちばしと脚、アイボリーの爪を合わせた。

- `chick-idle-v3.png`: 0歳。丸い頭と体、小さな翼と尾、短い足。3秒周期。
- `yearling-idle-v3.png`: 1歳。添付の幼羽の頭身を参考に、大きい頭、丸く短い胴、短い首と脚、小さな尾へ修正。約2頭身の幼羽。3.4秒周期。
- `adult-idle-v3.png`: 2歳以上。発達した翼と尾、太い脚、額羽の独立差分。3.8秒周期。
- `idle-prompts-v3.json`: 3種類の生成プロンプト全文とヒナの年齢表現の修正プロンプト。
- `yearling-proportions-v4.json`: 1歳の頭身を下げる修正プロンプト。添付画像は頭身のみ、画風は既存スプライトを参照。

本体の白〜灰色を10色、成羽のマゼンタの額羽を黄・赤・青・白・黒・虹に描画時に着色。
虹色は走行・表彰と同じ赤・橙・黄・緑・青・紫の6色を、各コマの額羽の横幅に沿って配置する。
半透明の微細なノイズを範囲の計算から除き、額羽全体にはっきり虹色が出るようにする。目、くちばし、脚、透過アルファは保持。
白に近い爪も脚の領域から判定して着色対象から外す。
各年齢の4コマを同じ倍率で縮小し、足元をそろえる。胸と頭の上下差を保ち、生成時の横ずれと接地位置のずれを補正する。
512×512の4コマを一度だけ着色・キャッシュし、CSSでコマを切り替える。
毎フレームのCanvas処理や画像の生成は行わない。`prefers-reduced-motion: reduce` と印刷時は最初のコマで静止。
一覧、ステータス、セール、購入確認、配合、誕生報告が同じ描画を使う。

プレビュー: `/chocobo-portrait-preview.html`。年齢3種、本体10色、額羽6色を確認できる。

## 保存済みの静止原画 v1

組み込み `image_gen` で生成した透過PNG（1254×1254）。原画はアルファを含めてそのまま保存。
実際の羽色は `public/js/ranch-portraits.js` で描画時に反映する。

- `adult-v1.png`: 2歳以上。やや見上げるクォータービュー。額羽をマゼンタで識別。
- `yearling-v1.png`: 1歳。やや見下ろす小鳥の頭身。額羽の差分なし。
- `chick-v1.png`: 0歳。見下ろす丸いヒナ。短い産毛・小さな翼と足。
- `PROMPTS.md`: 初回生成と幼羽・ヒナの修正に使ったプロンプト全文。

本体の白〜灰の羽を10色に着色し、目・くちばし・脚・透過アルファを保持する。
成羽は額羽を黄・赤・青・白・黒・虹へ独立着色。虹は額羽の高さ方向に色を補間。
黄金は羽の明暗に沿った淡い白金色の反射帯、その隣の濃い金色、深いブロンズ色の影で金属光沢を表現する。年齢のない源流・始祖は成羽で表示。
描画用512×512の画像は年齢・本体色・額羽色ごとにキャッシュし、色替え完了後に表示する。
