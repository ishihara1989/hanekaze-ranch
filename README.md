# 羽風牧場 / WING & WIND — v0.4

シロマと一緒にチョコボを産み、育て、競走へ送り出すブラウザの牧場ゲーム。レースでは育てたチョコボを信じて見守ります。ペース・スパート・進路はチョコボ自身が能力・性格と周囲の状況から判断します。

## 起動

```powershell
node server.cjs
```

**http://127.0.0.1:4173** を開きます。Node.js以外の依存パッケージは不要です。

[源流の遺伝情報・公開段階プレビュー](http://127.0.0.1:4173/genetics-preview.html) では32羽の源流と4公開段階を切り替え、並べて比較できます。セーブデータには触れません。`public/genetics-preview.html` を直接開くこともできます。

## GitHub Pagesへの公開

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定すると、`main` へのpushで検証・ビルド・デプロイが自動実行されます。公開はActionsの完了後に反映されます。

標準の公開URLは **https://ishihara1989.github.io/hanekaze-ranch/** です。[初回設定・ローカル確認・更新手順](docs/GITHUB_PAGES.md)を参照してください。

## 遊び方

1. 牧場名と冠名（1〜7文字のカタカナ）、冠名を前・後ろのどちらにつけるかを設定。3月第1週、瞬発力が持ち味の2歳牝羽1羽、20,000 Gからスタート。競走羽はモーグリの自動管理済み。シロマの案内で繁殖牝羽セールへ。
2. 繁殖牝羽を1羽迎え、種牡羽の一覧から配合。配合期間は3月第1週〜4月第4週で、遺伝効果の予測を5段階の範囲で確認できます。4週後に誕生します。セールと配合の期間中は、トップページにもそれぞれのボタンが出ます。
3. 「次の週へ」で成長を見守ります。報告はモーダルで開き、元の画面を保ったまま閉じたり、続けて週送りしたりできます。「4週進める」は月報・イベントと4週分のダイジェストをまとめて表示。名前登録が必要な週で停止します。
4. 2歳になる年の1月第1週に名前を登録し、「着実に勝つ / 重賞に挑む」を選択。名前は2〜9文字のカタカナ（長音「ー」も可）。性別に合う名前の候補が最初から入り、自由入力も可能です。登録後は改名できません。モーグリが調教・休養・出走を担当します。
5. 必要なときだけチョコボ・配合・施設・牧場手帳を開きます。1歳以下は成長率、2歳以上は現在ステータスを5段階で確認できます。繁殖担当は遺伝効果を合算して評価します。レース初勝利で研究所が解放され（建設2.5万G）、羽場や成長などの遺伝と競走情報、一方の記念施設で全遺伝の座位、記念館と銅像の両方で現在能力の数値を含む全情報が公開されます。

初年度に生まれた子は3年1月に2歳登録。年齢は1月に一斉加齢する暦年制です。週報の「観戦する」から、パドック→出走→レース→決着→勝利時の表彰を観戦できます。全6競走場の背景と羽色・額羽を反映した2D画面で観戦できます。実況ラミア・解説サハギン、実況字幕と任意の日本語音声、倍速・一時停止・カメラ切替に対応。戦績と過去の報告からも見返せます。走行データの記録はこの機能の追加後の出走からです。

配合の種牡羽一覧で「他の牧場」を選ぶと、**遺伝評価で絞り込む**から「瞬発力＝☆」「丈夫さ＝◎」などの条件を複数設定できます。指定した評価と一致し、すべての条件を満たす種牡羽を表示します（AND条件）。名前・牧場・勝ったレースやGⅠ勝利路線の検索とも併用でき、条件の追加・削除・クリアに対応します。羽場・コース・成長の遺伝は研究所の完成後に検索できます。

チョコボの個別画面から、繁殖牝羽の売却と自家製種牡羽を野生に返す操作ができます。どちらも確認ダイアログで確定すると羽房がすぐに1枠空き、血統と戦績は記録に残ります。売却額は繁殖牝羽セールと同じ競走実績の基準で計算し、季節を問わず売却できます。受胎中の繁殖牝羽は出産後に売却できます。種牡羽を野生に返しても受胎済みの子の血統は変わりません。源流・始祖・他牧場の種牡羽は返還の対象外です。

チョコボ一覧・個別画面・セール・配合の種牡羽一覧と父母の情報に、**源流（父系）** を常時表示します。父だけを世代数の制限なく遡って所属を確認し、始祖になっても源流は変わりません。始祖は各源流につき1羽で、オファーの報告と牧場手帳には、その源流の現在の始祖と、始祖入り時に先代が供用を終えることを表示します。

他牧場の導入羽は、生成時に使用した源流を所属として記録します。既存データの導入系統は記録済みの源流由来の欠点座（旧記録は牧場・繁殖区分）から補完し、子孫には父系で引き継ぎます。初期競走羽はカフェガナッシュ系です。導入以前の不明な父母は不明のまま保ち、保存済みの遺伝・能力・戦績・乱数は維持します。

競走は自牧場の出走羽を含めて12羽にそろえます。他牧場の継続シミュレーションはGⅠ37競走と路線ごとの前哨戦17競走だけに絞り、同じ個体の戦績・血統を追跡します。その他の条件戦・GⅡ・GⅢは自牧場が出走するときだけ実行し、クラスに応じた強さの対戦相手をその場で生成します。不足枠の低能力な一般参加羽とともに、これらの一時的な相手は牧場台帳・血統・繁殖市場に入らず、結果と観戦用の記録だけを残します。種牡羽・繁殖牝羽は継続シミュレーションの実績から選びます。

設定の **セーブ・ロード** には、オートセーブとは別の手動セーブスロットが5つあります。各スロットに保存日時・ゲーム内の日付・所持ギル・所有羽数を表示します。保存済みスロットへの上書きとロードは確認画面で確定します。ロードすると現在の牧場とオートセーブがその記録に置き換わります。週送り・オートセーブ・リセットでは手動スロットは変わりません。

**1〜5キー** で、どの画面からでも対応するスロットのロード確認を開けます。**Enter** でロードして再開、**Esc** でキャンセルします。文字入力中・別のダイアログ表示中・保存処理中はショートカットが反応しません。

自動保存・手動セーブはブラウザの **IndexedDB**（データベース `hanekaze-ranch`、ストア `saves`）に保存します。以前のlocalStorageのv4自動保存・5スロットは初回起動時にまとめて移行し、元データはバックアップとして残します。移行済みのデータを古いバックアップで上書きすることはありません。保存完了を待って操作を再開し、別タブとの競合も検出します。保存は同じブラウザ・プロファイル・URLに紐づき、JSONの書き出し・読み込みも引き続き使えます。

研究所Lv1から、配合画面で **実を使わない／カラブの実／ゼイオの実** を選べます。カラブの実はオス、ゼイオの実はメスが必ず生まれます（産み分け成功率100%）。実は各1,000ギルで、配合料金に加算して確定時に支払います。実を使わない場合は、追加料金なしで従来どおり性別を抽選します。

手動ロード・JSON読込・ページの再読み込みで再開すると、その先の孵化やレースなどの抽選は新しく行われます。同じ孵化前のセーブから再開しても、子の遺伝・能力・性別は固定されません。ただし産み分けの実を使った配合では、指定した性別をロード後も維持します。すでに生まれた羽の情報や記録済みの孵化報告・レース結果は、セーブどおりに復元します。

設定の **セーブをリセット** で序盤を再体験できます。牧場名・冠名・前後の位置を再設定し、確認ダイアログで確定するまで現在のデータは変わりません。保存は操作ごとに自動実行。JSONの書出し・読込にも対応します。設定のない既存のv4セーブは「羽風牧場・ハネカゼ・前につける」を引き継ぎます。

名前のもとは牡340語・牝370語。牡は速度・力・猛獣など、牝は花・宝石・音楽などを中心に、9割以上を5文字以下にしています。他牧場の競走羽や血統の元になる羽も、性別に合うストックと冠名から命名します。9文字以内に収まるストックを使い切った場合だけ、カタカナを機械的に組み合わせます。冠名を短縮することはありません。

現役競走羽、供用中の種牡羽、血統に残る牡羽、当年を含む直近20年のGⅠ勝者、源流・始祖、殿堂入りの名前は再使用できません。幼羽の候補も予約し、同時登録の重複を防ぎます。これらに該当しなくなった引退羽の名前は再使用できます。命名は遺伝・レース用の乱数を消費しません。

旧版のセーブは考慮せず、新しい保存キーに独立して保存します。v1〜v3のバックアップは新UIには読み込めません。旧キーは削除しません。`localhost` と `127.0.0.1`、異なるポートはそれぞれ別の保存先です。

競走羽の個別画面では、能力150を共通スケールにしたゲージで現在能力・加齢による低下・伸びしろを表示します。伸びしろの右端は各羽の能力上限です。今週から8週分の予定も確認でき、総合・重点調教、休養、出走レースの指定を保存すると週送りに反映されます。体調・出走条件・4週以上の出走間隔を守り、指定できないときは回復や調教を優先します。モーダルの外側クリックやEscapeで閉じられます。

身体8能力・管理2資質・性格6要素に、羽場適性4項目・コーナーと直線の適性3項目・成長3因子・羽色と額羽の遺伝を接続しています。路面とクッションへの適性は接地時の推進効率に作用します。右回り・左回り適性はコーナーの減速と余計な消耗を抑え、直線適性は速度とコーナー出口の推進力を高めます。他牧場はGⅠと選抜した前哨戦に出走し、GⅠ勝者を週報に掲載。年10羽・5年契約の種牡羽市場、部門別GⅠポイント表彰に接続しています。多世代のGⅠ難易度は継続調整の対象です。

テストは初回に `npm install`（または `pnpm install`）で開発用依存を入れます。IndexedDBの移行・保存失敗・同時更新の検証に `fake-indexeddb` を使い、ゲームの実行には追加の依存は不要です。

```powershell
npm test
npm run balance:opening -- --write
npm run test:long
```

通常テストは、他牧場の過去5年の実シミュレーション結果を `tmp/test-fixtures/` に一度生成してファイル間で共有します。初回は生成時間がかかり、関連するエンジン・遺伝・物理・番組コードが変わると自動で作り直します。状態はテストごとに独立して生成し、ゲームと同じGⅠ・前哨戦の進行を実行します。

初期配合のバランス検証は、産駒を実際に生成し、成熟時に潜在能力の90%を発揮する仮想状態で新羽・未勝利の4競走に挑みます。150週の全配合育成から、勝利経路の確認に切り替えています。新羽・未勝利には各週・距離・路面で一般参加だけの組があり、同等の適性・時期なら自動出走もこちらを優先します。育成期間・資金維持の監査とは別の確認です。[検証条件と結果](docs/gamebalance/OPENING_VALIDATION.md)。他牧場の6年間の世代交代と保存容量の検査は `test:long` で実行します。

新UIは `public/js/ranch-ui.js`、進行は `public/js/ranch-engine.js`、スタイルは `public/css/ranch.css`。旧 `game.js` / `world-views.js` は回帰検証用に残し、起動ページでは読み込みません。

牧場手帳の下の「図書館」に、攻略手順、用語、各能力と適性、配合・クロス・欠点、始祖入り、8大競走・三冠、施設、賞金・表彰、保存の16項目を収録しています。本文も含めて検索でき、ゲームの進行や研究施設の有無にかかわらず読めます。各画面の一般的なルール説明は図書館へまとめ、ホームや施設には牧場の雰囲気を伝える文章を置き、価格・期間・操作条件はその場で確認できます。記事は `public/js/ranch-library.js` で管理します。

一覧・ステータスには画像生成した年齢別ポートレートを使用。0歳は見下ろすヒナ、1歳はやや見下ろす小鳥、2歳以上はやや見上げるクォータービューで額羽の差分を描画します。本体10色・額羽6色に対応し、呼吸と小さな揺れの待機ループ付きです。[年齢・羽色プレビュー](http://127.0.0.1:4173/chocobo-portrait-preview.html)、[素材と生成プロンプト](public/assets/chocobo-portraits/README.md)で確認できます。

距離適性ラボは **http://127.0.0.1:4173/balance-lab.html**。独立した実験として引き続き利用できます。

ゲーム内のレース観戦はCanvas 2Dで描画します。倍速・一時停止・注目羽・カメラ・音声設定を選べます。「動き」は足と景色のテンポを選ぶ設定で、既定は「きびきび」。時計・着順・実際の羽同士の位置関係は共通の走行記録に従います。

レースはUIに依存しない内部シミュレーションで一度計算し、内寄せ・進路変更を含む走行記録を保存します。2D画面はその記録から再生フレームを受け取って描画します。観戦や巻き戻しでレースを再計算することはありません。

2Dレース試作は **http://127.0.0.1:4173/race-2d-preview.html** に引き続き残しています。競走場・左右の向き・描画ピッチの比較と、直線・カーブへの区間ジャンプはこちらで確認できます。素材一覧は **http://127.0.0.1:4173/race-2d-backgrounds.html**。
