# 羽風牧場 / WING & WIND — v0.4

シロマと一緒にチョコボを産み、育て、競走へ送り出すブラウザの牧場ゲーム。序盤のUIと進行を新しくしました。

## 起動

```powershell
node server.cjs
```

**http://127.0.0.1:4173** を開きます。Node.js以外の依存パッケージは不要です。

## 遊び方

1. 3月第1週、所有0羽、20,000 Gからスタート。シロマの案内で繁殖牝羽セールへ。
2. 繁殖牝羽を1羽迎え、種牡羽の一覧から配合。4週後に誕生します。
3. 「次の週へ」→「シロマの報告」を繰り返して成長を見守ります。「4週まとめて進める」は月報やイベントで停止。
4. 2歳になる年の1月第1週に名前を登録し、「着実に勝つ / 重賞に挑む」を選択。モーグリが調教・休養・出走を担当します。
5. 必要なときだけチョコボ・配合・施設・牧場手帳を開きます。GⅠ初勝利で研究所が解放され、性格・現在能力・遺伝を段階的に詳しく調べられます。

初年度に生まれた子は3年1月に2歳登録。年齢は1月に一斉加齢する暦年制です。現時点の観戦は結果・着順・時計の確認です。

設定の **セーブをリセット** で序盤を再体験できます。確認ダイアログで確定するまで現在のデータは変わりません。保存は操作ごとに自動実行。JSONの書出し・読込にも対応します。

旧版のセーブは考慮せず、新しい保存キーに独立して保存します。v1〜v3のバックアップは新UIには読み込めません。旧キーは削除しません。`localhost` と `127.0.0.1`、異なるポートはそれぞれ別の保存先です。
