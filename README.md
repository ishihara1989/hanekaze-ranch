# 羽風牧場 / WING & WIND — v0.3

> 現在は試行錯誤中のプロトタイプです。本書と関連資料は現在の実装を記録する暫定文書であり、確定仕様ではありません。今後のユーザーの指示と衝突する場合は、指示に沿って仕様・設計・実装の変更を検討できます。文書の記載を現状維持の制約とはしません。

配合・競走観戦・年間経営を遊べる、ブラウザ用のチョコボ牧場シミュレーションです。

## 起動

`node server.cjs` を実行して **http://127.0.0.1:4173** を開きます。Node.js以外の依存パッケージはありません。`public/index.html` を直接開く方法も使えますが、保存にはローカルサーバー経由を推奨します。

3Dチョコボの試作モデルは **http://127.0.0.1:4173/chocobo-preview.html** で確認できます。巡航では羽を閉じ、カーブ・下り坂・スタートダッシュ・ラストスパートでは羽を広げるアニメーション付きです。編集用BlenderファイルとGLBを同梱しています。[モデルの仕様・編集方法](public/assets/chocobo/README.md)を参照してください。既存の観戦画面は引き続き2Dです。

## 距離適性ラボ

**[距離適性ラボ](http://127.0.0.1:4173/balance-lab.html)** で1200〜3600m（400m刻み）の各距離で最速になる7羽を比較できます。内部パラメータの編集、速度・有酸素出力・無酸素容量・脚疲労のグラフ付き。既存ゲームの能力への対応とは独立した実験です。[設計と使い方](docs/gamebalance/README.md)・[実測結果](docs/gamebalance/RESULTS.md)を参照してください。`node tools/simulate-balance.cjs` で同じ比較を再実行できます。

同じラボの「ユウナギ・2400mで比較する」では、**巡航からラストスパートする方が速い例**も確認できます。一定ペースも細かく探索して比較します。[作戦比較の結果](docs/gamebalance/PACING.md)。再計算は `node tools/compare-pacing.cjs --write`。

ゲームで見える能力と内部物理の対応は [能力・遺伝・性格・調教の設計案](docs/gamebalance/ATTRIBUTE_MAPPING.md) に整理しました。[生成個体の試走結果](docs/gamebalance/MAPPING_RESULTS.md) は `node tools/audit-trait-mapping.cjs --write` で再生成できます。身体能力の変換を独立試作した段階で、既存の育成・保存データにはまだ適用していません。

## 最初の遊び方

1. 「次の週へ」を押して時間を進めます。開業時からリナ調教師が専属で、調教と4週先までの出走予定を組みます。
2. 出走がある週は「観戦する」か「観戦せずに進める」かを選択。賞金・出走手当を獲得し、収得賞金が増えると昇級します。
3. 月が変わると月次まとめを表示。全体では獲得資金と経費、個別では羽ごとの出走結果・調教内容・来月の出走予定を確認できます。
4. 自分で走らせたいときは、手動モードにして「番組表」から出走を予約するか、「競走観戦」で今週の競走にすぐ出走させます。
5. 「配合ラボ」で種牡羽と繁殖牝羽を選んで種付け。4週後に出産します。
6. 子は1歳から調教、2歳から競走へ。羽市場で売買することもできます。

新規開始時は12,000 G、競走羽4羽、繁殖羽2羽。競合は6羽主・6牧場・144羽から始まり、同じ世界で競走・育成・繁殖・売買を続けます。

## 主な機能

- 1年48週、12か月×4週。1週・4週・1年の進行と途中停止。
- 週送り中心の進行：出走予定（調教師の編成または12週先までの予約）、出走週の観戦選択、月次まとめ（全体・個別）。
- 新羽・未勝利・1勝・2勝・3勝クラス・オープン。固定日程の重賞27競走（GⅠは原作『チョコボスタリオン』の競走名）。
- 天空神殿・熱帯密林・秘境遺跡（芝）、王宮都市・砂浜公園・山岳廃坑（ダート）の6競羽場。原作『チョコボスタリオン』の競羽場です。
- 直線2本と曲線2本の周回路。発走位置は距離によって変化。秒速・実距離から時計を計算し、再生は1/2/4/8倍速。
- 30能力の遺伝・固定上限・育成。♂の個体差−3〜＋7、♀−3〜＋3。
- 固有の羽主・生産牧場・血統・戦績・取引履歴。売却後も同じ羽が世界に残ります。
- 幼羽は親の実績、繁殖牝羽は親と自身の実績から価格を算定。種付け料は種牡羽の競走成績によって変化。
- 飼料費・維持費・調教師給与・出走料・賞金・出走手当・売買・種付け料の収支帳。
- 自動保存、JSONバックアップ、旧版データの自動移行。競走中の中断は再開時に同じ乱数で精算。

## 年齢と繁殖

年齢は経過48週で1歳加算される方式です。1月に一斉加齢する方式ではありません。

- 0〜1歳：幼羽。調教は1歳から。
- 2〜9歳：競走羽。好成績の4〜6歳は自動運営の設定により繁殖入り。手動では自分で引退を決定。
- 10歳：全羽が競走引退。
- 3〜30歳：種牡羽・繁殖牝羽として利用可能。
- 31歳：野生へ帰り、経費がかからなくなる。血統記録は残る。

種付けには出産用の空き羽房が必要です。受胎期間は4週、出産が31歳以降になる種付けはできません。

## セーブと互換性

同じブラウザ・同じURLで自動保存されます。`localhost` と `127.0.0.1` は別の保存先です。遊び方画面からJSONを書き出せます。

v1/v2の保存を開くと、元のデータを localStorage の `hanekaze-ranch-v1-before-v3` に予備保存し、v3に移行します。成鳥は2歳以上、幼鳥は0〜1歳へ換算し、所有羽・血統・能力上限・戦績・資金を継承。新しい経費に備えて、一度だけ6,000 Gの移行準備金を加えます。v1の旧3能力はv2の固定上限方式への変換も行います。

進行中の競走は出走料を支払った状態で登録情報と乱数種を保存します。ページを閉じても再開時に精算するため、出走料や賞金を二重計上しません。

## 構成と検証

- `public/index.html`：ブラウザの起動ページ。`public/js/` のスクリプトを順番に読み込みます。
- `public/js/model.js`：30能力・遺伝・育成・走行物理・コース位置。
- `public/js/world.js`：羽主、年間番組、出走資格、売買、繁殖、会計、年齢処理。
- `public/js/world-views.js`：番組表、羽市場、調教師、経営、競合牧場、成績画面。
- `public/js/game.js`：画面操作、観戦、保存。
- `public/css/style.css`：PC・モバイル向け表示。
- `server.cjs`：`public/` 内の指定ファイルだけを配信。
- `tests/`：Node.js組み込みテスト。
- `docs/`：実装概要、能力・経営仕様、初期構想メモ。

`node --test tests/game.test.cjs tests/model.test.cjs tests/world.test.cjs` で遺伝・調教・年齢境界・会計・売買・保存移行・競走再開・年単位の進行を検証します。

全体の構造・保存データ・処理順・変更箇所は [実装概要（暫定）](docs/IMPLEMENTATION.md)、個別の数値や効果は [能力仕様（暫定）](docs/STAT_SYSTEM.md) と [年間経営仕様（暫定）](docs/WORLD_SYSTEM.md) を参照してください。

試作品のため、1競走あたり自牧場からは1羽、出走数は最大6羽です。NPCが不足する番組は不成立となります。生育・繁殖・会計は簡易モデルで、価格や賞金などのバランスは初期設定です。3D、騎手、実際の進路取り、事故・疾病、賭け券、対人戦は未実装です。
