# ゲーム能力・遺伝・調教とレース物理の対応案

2026-09-30。**仕様案と独立した試作**。旧版の保存データ・30能力には適用しない。v4の新進行では、身体変換・遺伝品質・成長調教・基本的な性格制御を接続した。[接続範囲と未実装部分](../OPENING_REDESIGN.md)・[序盤の通し検証](OPENING_VALIDATION.md)を参照。本書の未検証と記した詳細すべてを実装済みとするものではない。

路面・クッション適性、羽色、成長3因子については、後から実装した[遺伝拡張の仕様](../GENETICS.md)を優先する。本書の独立試走と、v4に接続後の検証は区別する。

推奨構造は「遺伝で体質と伸びしろを決める → 成長・調教で現在能力になる → 身体能力を物理量へ変換する → 性格と騎乗でその使い方を決める」。距離適性・脚質を直接の速度ボーナスにしない。

対応式と個体生成は [trait-mapping.js](../../public/js/trait-mapping.js)、再現可能な試走は [MAPPING_RESULTS.md](MAPPING_RESULTS.md)。**試走で検証したのは身体能力の変換・条件付き能力分布・単独走だけ**。遺伝子の交配、性格の行動制御、馬場、成長、調教、出走後の管理は本書の設計案であり、検証済みの挙動ではない。

## 1. プレイヤーに見せる能力

レース用の身体能力8つ、管理用の資質2つ、性格6つを基本にする。コース適性と成長型は別欄。序盤の一覧では「速さ・持久・末脚・扱いやすさ」の要約も出せるが、内部計算には元の能力を使う。

| 身体能力 | レースで何が違うか | 主な内部パラメータ | 遺伝・成熟と調教の関係 |
|---|---|---|---|
| 最高速 | 十分な出力があるときに出せる速度の上限 | `maxSpeed` | 遺伝・成熟が主。動作の洗練で少し伸びる |
| 心肺 | 高い出力を継続して供給できる | 有酸素上限 `Amax` → `criticalSpeed` | 遺伝上限あり、有酸素調教でもかなり伸びる |
| 瞬発力 | 短時間の出力、加速や登坂で出せる力 | `anaerobicPower`, `maxForce` | 筋特性と成熟が主、坂路・速い運動でも伸びる |
| スパート容量 | 心肺出力を超えて使えるエネルギーの量 | `reserveCapacity` | 遺伝の影響大、速い運動の反復で一部伸びる |
| 脚持久力 | 同じ力を出し続けたときに脚が疲れにくい | `legEndurance` | 体質と走り込みの両方 |
| 走行効率 | 同じ速度に必要なエネルギーが少ない | `linearCost` | 体形・歩様と、動作の学習の両方 |
| 立ち上がり | 発走・加速後に心肺供給が追いつく速さ | `cardioTau`, `initialAerobic` | 体質と準備・調教の両方。ゲート反応とは別 |
| 疲労耐性 | 脚が疲れた後の効率悪化、無酸素使用による脚疲労が小さい | `fatigueCost`, `anaerobicFatigue` | 体質の影響大、調教で一部改善 |

「脚持久力」は疲労が**たまる速さ**、「疲労耐性」は疲労の**結果と高出力運動への耐性**。この2つを分けると、長く走れる個体と、速く走っても崩れにくい個体を区別できる。実際の加速度は出力・抵抗・速度・疲労から計算し、「加速」という独立倍率は重ねない。

| 管理用の資質 | 役割 |
|---|---|
| 丈夫さ | 同じ運動量でも出走後の体力・脚への残留負担が小さい。主に遺伝と健全な成長 |
| 回復力 | 休養で体力が戻り、脚の残留疲労が解消する速さ。主に遺伝、生活管理と基礎調教が補助 |

これらの資質も50〜150。**現在の体力0〜100、現在の脚部疲労0〜100とは別**。丈夫さや回復力が高い血統は、同じ一戦の最高時計だけでなく、年間の調教量・出走数で有利になる。

| 性格 | 主な効果 | 交換条件と育て方 |
|---|---|---|
| 根性 | 疲れてからも指示を実行し、余力を使い切れる | 基本的にプラス。主に成功体験を伴う持続・終いの調教で育てる |
| 走る意欲 | 疲れを嫌って緩めにくい、自発的に走る | 自制不足だと道中で飛ばす。高いこと自体を矯正する必要はない |
| 賢さ | ペース判断、作戦変更、勝てそうなときの余力温存 | 疲労を避ける傾向も持つ。根性・意欲不足だと早く緩めやすい |
| 自制心 | 走りたい・追いたい気持ちがあっても指示ペースを守る | 基本的にプラス。折り合い・ペース調教で伸ばしやすい |
| 羽混み耐性 | 接近・包囲で慌てず、指示を実行する | 基本的にプラス。段階的な集団慣らしで育つ |
| 闘争心 | 相手への反応、競り合ったときの集中と再加速 | 早い競り合いで消耗しやすい。高低の優劣ではなく使い方 |

賢さと自制心は別にする。「走るのが大好きだが折り合いがつく」「賢いが競り合うと熱くなる」を作れるため。学習速度・集中のむら・ゲートの慣れは補助特性や習熟度で扱い、初期段階で表示能力をさらに増やさない。従来のリーダー気質は、必要なら「前へ行きたがる」という補助的な傾向として残す。

## 2. 交換条件のある遺伝と、純粋に有利な遺伝

### 2.1 二つの独立した体質軸

| 軸 | −側 | ＋側 | 備考 |
|---|---|---|---|
| `D`：筋・代謝構成（−1〜+1） | 瞬発型：最高速・瞬発力・無酸素容量が高い | 持久型：心肺・脚持久力・効率が高い | 主に得意距離を動かす |
| `R`：出力の配分特性（−1〜+1） | 持続型：立ち上がりが速く、高い巡航を続けやすい | 放出型：高い速度・出力と容量を持ち、溜めた力をまとめて使える | 主に先行維持と終盤勝負の身体的な向きを動かす |

「瞬発型＝必ず差し」「持久型＝必ず逃げ」にはしない。短距離の先行型、短距離の差し型、長距離の先行型、長距離の差し型の4組が成立する余地を持たせる。

Rは「後半になったら強くなる遺伝子」ではない。放出型は最初からその出力を出せるが、早く出すと疲労コストを残りの距離にも負担する。持続型の先行適性も最高速ではなく、**前を維持する費用が小さい**ことから生じる。放出型の瞬発力がゲート直後の加速でも役立つのは自然なので、先行型だけに発走速度補正を付けない。

各能力の成熟・十分な調教後の中心を、まず次で置く。

```text
μ_i = q_i + d_i × D + r_i × R
潜在能力 C_i ~ Normal(μ_i, 10²) を50〜150で切断
```

| 能力 | `d_i`（持久側へ寄せる効果） | `r_i`（放出側へ寄せる効果） |
|---|---:|---:|
| 最高速 | −18 | +6 |
| 心肺 | +12 | −5 |
| 瞬発力 | −14 | +10 |
| スパート容量 | −20 | +12 |
| 脚持久力 | +16 | −3 |
| 走行効率 | +4 | −1 |
| 立ち上がり | −4 | −14 |
| 疲労耐性 | +7 | −14 |

**大容量は長距離型専用にしない。** 無酸素容量は短距離で一気に使えるエネルギーでもある。試作では容量まで持久型側に寄せると、短距離でも持久型が強くなりすぎた。長距離型は心肺と効率で、そもそも予備を減らさず走れるようにする。

D/Rは能力を生成するときだけ使う。物理変換で再度D/R補正を掛けたり、1200m向き・3600m向きの倍率を足したりしない。

### 2.2 品種改良で伸びる品質

`q_i` は単なる総ポイントの配分ではなく、改良できる遺伝的な品質。筋の品質、心肺の品質、運動の効率、組織の丈夫さ、回復の資質など、複数の遺伝群に分ける。好ましい組合せを作ることで、同じD/Rの血統でも複数の能力を同時に改善できる。

初期集団では中心70前後、改良後の集団では100前後を目安とする。**ゲームが進んだから自動的に上げる数値ではなく、選抜・交配で集団の遺伝子頻度が変わった結果**とする。調教した値は子へ直接遺伝しない。

交配モデルの出発案は、品質群ごとに32か所の二倍体遺伝子を持つ方式。

```text
品質群の値 q = 50 + 1.25 × 有利なアレル数（0〜64個）
有利なアレル頻度0.25なら E[q]=70、0.625なら E[q]=100
各座位について父母から1本ずつ受け継ぐ
```

これは遺伝子数を生物学的に主張するものではなく、改良が段階的に進むためのゲーム表現。複数能力で一部の品質群を共有し、残りは別群にすれば「総合的に良い血統」と「部分的に優秀な配合素材」の両方が残る。一つの品質値だけで全能力が決まる構成にはしない。試走では影響を切り分けるため全群の中心を70または100にそろえた。

D/Rを均等な微小効果の多数遺伝子だけで作ると中央に集中しすぎる。大きめの効果を持つ体質因子と小さな修飾因子を組み合わせ、創始血統に両極の系統を配置する案がよい。例えば主因子−0.65/0/+0.65と修飾±0.35。Rに実在の「逃げ遺伝子」があるという意味ではない。

個体差の正規乱数は生まれたときに保存し、画面更新・出走・再読み込みで再抽選しない。交配時には親の表現能力そのものを平均せず、遺伝子を継承してから子の個体差を一度だけ抽選する。子の品質分布と成績の世代推移は、この交配機構を作ってから別途検証する。

強い血統が長短両方で弱い血統に勝つことは許す。負の相関を要求するのは**品質をそろえたときの体質差**。品質差まで含めた全個体で必ず負の相関になるよう補正すると、品種改良の楽しさを消してしまう。

### 2.3 「正規分布・σ10・50〜150」の解釈

正規分布は無限の裾を持つので、厳密な正規分布と硬い上下限は両立しない。本案は「切断前のσが10、50未満・150超は棄却して再抽選」。単純なclampでは下限50に大量の個体が集まるため避ける。

品質70、D=R=0では実測平均約70.5、σ約9.4。品質100では約100、σ約10。さらにD/Rを混ぜれば集団全体の分散は増える。下限付近では体質差も圧縮される。**全世代・全遺伝型混合で平均70/100、σ10を厳密に保つ仕様とはしない**。

試走は成熟・十分に調教済みの個体を想定する。若鳥や調教不足の現在能力まで同じ分布になるとはしない。能力を毎週正規分布から作り直すこともしない。

## 3. 現在能力から物理量への対応式

`z_X=(X−100)/50`。50なら−1、100なら0、150なら+1。以下が試作で使った式。パーセント倍率ではなく、能力差が有限な物理差へ変わるようにする。

| 物理量 | 式 | 能力50〜150による範囲 |
|---|---|---|
| 最高速度 `maxSpeed` | `23 + 2 z_最高速` | 21〜25 m/s |
| 有酸素上限 `Amax` | `64 exp(0.18 z_心肺)` | 約53.5〜76.6 W/kg |
| 走行コスト `linearCost` | `2.2 exp(−0.09 z_走行効率)` | 約2.407〜2.011 |
| 三次コスト `cubicCost` | `0.004` | 共通。通常の調教では下げない |
| 無酸素容量 `reserveCapacity` | `2400 exp(0.50 z_スパート容量)` | 約1456〜3957 J/kg |
| 最大無酸素出力 `anaerobicPower` | `56 exp(0.45 z_瞬発力)` | 約35.7〜87.8 W/kg |
| 最大推進力 `maxForce` | `9.4 + 1.3 z_瞬発力` | 8.1〜10.7 N/kg |
| 脚持久 `legEndurance` | `430 exp(0.50 z_脚持久力)` | 約261〜709 秒 |
| 疲労によるコスト増 `fatigueCost` | `0.45 exp(−0.50 z_疲労耐性)` | 約0.742〜0.273 |
| 無酸素使用による脚疲労 `anaerobicFatigue` | `0.30 exp(−0.65 z_疲労耐性)` | 約0.575〜0.157 |
| 心肺時定数 `cardioTau` | `9 exp(−0.50 z_立ち上がり)` | 約14.84〜5.46 秒 |
| 発走時有酸素比 `initialAerobic` | `0.4 + 0.1 z_立ち上がり` | 0.3〜0.5 |
| レース中のW回復係数 `recoveryRate` | `0.06 + 0.02 z_心肺` | 0.04〜0.08 |

最後に `linearCost × vc + cubicCost × vc³ = Amax` を解いて `criticalSpeed=vc` を求める。全能力範囲で約15.73〜20.63m/s。最高速度の最小21m/sより低く、入力の矛盾が起きない。

**走行効率を上げるときは有酸素供給量を固定してvcを再計算する。** 既存エンジンはvcからAmaxを導出するため、vcを固定したまま走行コストだけ下げると供給まで下がってしまう。変換側でこの整合性を取る。

疲労コストも無酸素由来の脚疲労も、能力150でも正。疲労耐性が低いと最悪1.742倍、高いと1.273倍の走行コストになる（L=1時）。高能力でも疲労による推進力上限低下は残る。根性によってこれらの係数を0にすることもない。

係数・範囲はチョコボのゲーム用仮説で、実馬の測定値として採用したものではない。既存7羽の実験プリセットには比較用のゼロ係数が残るが、**この新しい能力マッピングから生成する個体にはゼロを許していない**。既存プリセットは遺伝個体の生成例とは区別する。

## 4. 遺伝・成長・調教を分ける

身体能力の成熟上限Cは遺伝と固定個体差で決める。現在能力Sは年齢による成熟gと、調教状態Tで決める案とする。

```text
S_i = 50 + (C_i−50) × g_i(age) × (1−t_i+t_i×T_i)
g_i, T_i は0〜1。t_iは成熟後に調教で埋める割合。
```

| 能力 | 調教で埋める割合 `t_i` の初期案 |
|---|---:|
| 最高速 | 0.15 |
| 心肺 | 0.45 |
| 瞬発力 | 0.35 |
| スパート容量 | 0.30 |
| 脚持久力 | 0.45 |
| 走行効率 | 0.40 |
| 立ち上がり | 0.50 |
| 疲労耐性 | 0.35 |
| 丈夫さ | 0.10 |
| 回復力 | 0.25 |

例えばC=110、成熟済みなら、最高速は調教不足でも101、心肺は83から110へ伸ばせる。この割合は**遺伝率の推定値ではなくゲームの育成幅**。成長の遅い血統は能力Cが低いのではなくgの上昇が遅い。早熟・長命は生涯の成長曲線を変え、通常の調教で毎週早熟や寿命そのものを増やさない。

50は能力評価の下限であり、幼鳥の実測速度を保証する値ではない。未成熟で出走できない時期は能力予測を表示し、幼鳥を成鳥用の走行モデルへ直接投入しない。

性格に同じ「遺伝で固定された低い上限」を使うと、根性を調教で何とかする方針と衝突する。性格は遺伝による初期傾向、デビュー前の環境、調教履歴の合成にする。

| 性格 | 遺伝 / 生育 / 調教の寄与を調整する初期目安 |
|---|---|
| 根性 | 10 / 25 / 65 |
| 走る意欲 | 20 / 55 / 25 |
| 賢さ | 20 / 45 / 35 |
| 自制心 | 10 / 30 / 60 |
| 羽混み耐性 | 20 / 35 / 45 |
| 闘争心 | 25 / 45 / 30 |

これは作用幅を配分するための比率であり、観測分散の遺伝率ではない。性格を強い遺伝上限で閉じず、初期傾向や習得速度に遺伝の影響を持たせる。最終の尺度は50〜150にそろえる。

野性的な環境は意欲・競争への反応・刺激への慣れ、穏やかな環境は自制・人の合図の学習・落ち着きへ寄せる程度から始める。**野生育ち＝低知能、穏やか育ち＝根性なし、と固定しない**。環境の詳細なメニューやイベントは今回決めない。

## 5. 性格は「使える力」と「使おうとする力」の間に入れる

物理側が決めたAmax・W・力の上限・脚疲労は尊重し、性格は目標速度、ペース指示への追従、どこまで予備を使うかに作用させる。心肺供給やエネルギーを性格だけで増やさない。

### 5.1 根性・走る意欲・自制心

導入用の簡単な式の案（未実装）。性格は `u_X=(X−50)/100` にして0〜1へ正規化する。

```text
本人が感じる負担 f = clamp(0.6 L + 0.4 (1−W/Wmax), 0, 1)
疲れを避ける傾向 a = clamp(0.18 + 0.08 u_賢さ − 0.08 u_意欲 − 0.10 u_根性, 0, 0.30)
自主的な予備の保留率 b = 0.12 − 0.10 u_根性
本来の出力要求 Pplan に対して、自発的に出そうとする上限は Pplan × (1−a f)
Wがb×Wmax未満なら追加で要求を緩める。物理的なW=0より手前で諦め始める表現。
```

この下げ方は初期案で、低能力を重ねても止まってしまわない程度に制限する。根性の高さによって消えるのは**自主的な手控え**。物理的な疲労・エネルギー不足による減速は残す。

走る意欲の高い個体には、例えば `最大+6% × u_意欲 × (1−u_自制心)` の目標速度への上振れを加える。闘争心による反応は近くの相手がいる場合だけ。毎フレーム独立乱数にせず、数秒持続する反応にし、時間刻みを変えても挙動が変わりにくくする。

根性は基本的に上げ得でよい。高い能力にわざと故障率などの罰を付ける必要はない。実際に最後まで力を出した結果として出走後の消耗が増えるため、十分な管理上の交換条件になる。意欲と自制心を両方高められる個体も許す。訓練時間と完成までの長さが育成上の費用になる。

### 5.2 賢さと勝つための温存

賢さはペース判断の誤差を減らし、残距離・見えている相手との間隔と速度から余裕を推定する。見えていない相手のW、真の能力、未来の速度は読ませない。賢い個体でも推定が外れれば負ける。

同じ作戦の「時計優先」と「勝利優先」を区別する。時計優先では自己最速を狙う。勝利優先では、着差が安全幅を超え、相手の接近を見ても余裕があると判断したときだけ要求を数%緩める。残りが長いほど安全幅を広くし、追われたら再加速する。緩めた後に再加速できるかも本人の出力・疲労の範囲内。

ユーザーのいう「ギリギリ勝てる程度」は、完全に未来を読んだハナ差ではなく、**不確実性を含む小さな安全幅**で表現する。高い賢さほど必要な安全幅を小さくできる。回復を直接速くするボーナスは付けず、実際に使った力が少なかった結果として体力・脚を残す。

### 5.3 羽混みと身体との相性

羽混み耐性は接近・包囲時のストレス、合図への反応遅れ、過剰な加速・減速を抑える。物理的に進路が塞がっている状況は別に判定し、高い耐性で前の個体を通り抜けることはできない。

| 身体の向き | 噛み合いやすい性格・調教 | 噛み合わない場合 |
|---|---|---|
| 高心肺・立ち上がり・疲労耐性 | 自制心、根性、安定した走る意欲 | 闘争心で序盤の競り合いに乗りすぎると先行維持の利点を失う |
| 高出力・高容量・高最高速 | 自制心、賢さ、終盤の根性、羽混み耐性 | 意欲が自制を上回ると溜める前に使い、鈍る |
| 心肺が低めの短距離型 | 走る意欲、合図への反応、短い集中 | 賢さが高くても疲労回避ばかり強いと使い切れない |
| 出力控えめの長距離型 | 自制心、配分判断、持続する根性 | 毎回短い全力加速を繰り返す性格では強みが生きない |

短距離・先行型にも自制心は役立ち、差し型にも意欲は役立つ。型ごとに性格ボーナスを足すのではなく、相性は行動と消費から生じさせる。

## 6. コーナー・重い馬場・芝とダート

芝/ダートと、軽い/重いは別軸。各区間に硬さ、沈み込み、グリップ、凹凸、カーブ半径を持たせる。個体には遺伝的な骨格・接地の向きと、その路面を走った習熟を持たせる。プレイヤーには「旋回」「軽い馬場」「重い馬場」「芝」「ダート」の評価として要約できるが、五重に速度倍率を掛けない。

| 適性・特性 | 向いている条件で改善する物理量 | 調教で変えられるところ |
|---|---|---|
| 旋回・姿勢安定 | 横方向に使える力の上限、無駄な減速と再加速 | コーナーの習熟・指示への反応。骨格の上限は遺伝 |
| 沈み込みへの強さ | 軟らかい路面による追加の一次コストを小さくする | 踏み方・姿勢の習熟。足の形状は大きく変わらない |
| 接地・グリップ | 滑りによる推進力の上限制限を緩和 | 路面への慣れ、接地の安定 |
| 軽い馬場での反発利用 | 硬めの路面で一次コストがやや低くなり、速い動作の速度上限を発揮できる | 動作の洗練。最高速や出力自体を別途二重加算しない |
| 芝・ダートへの接地の向き | 路面別の滑り・沈み込みへの適合 | 経験で不慣れの損失を減らす |

地面対応の遺伝は、例えば「反発を生かす ↔ 沈み込みに強い」「芝的な接地 ↔ 砂を捉える接地」の二軸を出発点とする。どちらかに寄るほど反対側は少し不利。ただし全般的な姿勢制御・健全な組織の品質は両方を改善できる。これはゲームの設計上の対立軸であって、実在の単一遺伝子や厳密な生体相関を主張しない。

区間への適用案：

```text
c1_eff = c1 × max(0.92, 1 + 沈み込みコスト×(1−0.5×適合度) − 反発利用の小さな利得)
F_forward ≤ min(筋力側の上限, グリップ側の上限)
旋回の横加速度 = v² / 半径
推進と旋回が使う力の合計は身体と接地の上限内に制限
```

適合度が高くても重い馬場の追加コストは原則残す。導入時は追加抵抗0〜30%、グリップによる力制限0〜20%程度の幅から試し、極端な条件は別コースとして扱う。数値は未校正。馬場でc1が変わっても本人のAmaxを再計算して増減させず、Amaxを保ったまま新しいvcを求める。

コーナーでは接地・横方向の力の制約をエンジンへ追加する必要がある。現行 `RacePhysics` の一定 `maxForce` だけでは代用しきれない。半径が大きく十分グリップがあるならコーナー適性差をほぼ出さない。傾斜では重力による必要仕事を残し、登坂能力は力・心肺・歩様で表す。耐風で空気抵抗を消すのも避ける。

## 7. 調教の種類と伸び方

「追い切り」は何でも伸びる能力名ではなく、短い強めの刺激を入れる練習の形式。何m・どの強さ・単走か併走かで内容を分ける。基礎づくり、強い刺激、技術・性格の学習、回復を組み合わせる。

| メニュー | 主に伸びるもの | 補助的に伸びるもの | 体力消費 / 脚負担の相対目安 |
|---|---|---|---|
| ゆったりした長い走り込み | 心肺・脚持久力 | 走行効率・自制心 | 中 / 低〜中 |
| 持続する一定ペース走 | 心肺・走行効率 | 根性・ペースへの習熟 | 中 / 中 |
| インターバル | 心肺・スパート容量 | 疲労耐性・立ち上がり | 高 / 中〜高 |
| 短い高速追い切り | 瞬発力・最高速の発揮 | スパート容量・立ち上がり | 中 / 高 |
| 坂路 | 瞬発力・脚持久力 | 心肺・疲労耐性 | 高 / 中〜高、下りも負担を考慮 |
| プール | 心肺の維持・改善 | 気分転換・基礎体力 | 中 / 低。走行接地への適応はほぼ伸びない |
| 折り合い・指定ペース走 | 自制心・賢さの実行面 | 走行効率 | 低〜中 / 低 |
| 併走・集団慣らし | 羽混み耐性・自制心 | 闘争心の使い方・合図への反応 | 低〜中 / 強度次第 |
| 余裕を残した終いの加速 | 根性・最後まで走る経験 | 瞬発力・意欲 | 中 / 中 |
| ゲート・コーナー・路面慣らし | 各技能・姿勢制御 | 自制心・落ち着き | 低〜中 / 条件次第 |
| 休養・放牧・ケア | 体力回復・脚疲労の解消 | 心理的な立て直し | 回復 / 回復 |

プールを万能な脚づくりにしない。負荷が低いのは主に地面への接地で、体力消費がないわけではない。坂路も無条件に低い脚負担とはしない。根性は限界まで追えば必ず上がる仕組みにせず、達成可能な指示を最後まで実行した成功体験で伸びる。

調教によるTの更新は、例えば `ΔT = メニュー刺激 × 学習効率 × 回復状態 × (1−T)`。完成に近いほど伸びが鈍る。運動しない期間に少し低下する成分と、覚えた技能として残る成分を分ける。休ませたら全能力が同率で消える方式は避ける。

強い調教の反映は休養後。週内に練習で即座に能力が上がり、同じ週のレースで疲労なしに得をする形を避ける。数値の週間増分は、既存の週48回カレンダーに合わせて「何週でデビュー水準・何週で完成するか」を先に決めて校正する。生理研究の練習日数をそのままゲームの週数へ置き換えない。

## 8. 出走後の体力と脚部疲労

レース中のW/Lと、牧場で管理する体力C/脚部疲労Bは別の状態。

| 状態 | 尺度 | 意味 |
|---|---|---|
| レース中のW | J/kg | 短期的に使える予備エネルギー |
| レース中のL | 0〜1 | そのレースでの脚の機能低下 |
| 管理体力C | 0〜100、高いほど元気 | 翌週以降にも残る全身の回復状態 |
| 管理脚部疲労B | 0〜100、低いほど健全 | 翌週以降にも残る脚の負担 |

管理用の負担を計算するため、既存の `energyUsed`, `reserveSpent`, `reserveRecovered` に加えて、最低W比率・Wが10%未満だった時間・高い力を出した時間を記録する。最後のWだけを見ると、途中で使い切って回復させた個体が無消耗扱いになる。

ゲーム用の初期校正式（未実装）：

```text
e = 総仕事量 energyUsed / 12000
w = 総無酸素使用量 reserveSpent / Wmax       # 回復して再使用すれば1超もあり得る
h = Wが10%未満で走った秒数 / 60
j = ∫max(F/4−1, 0)² dt / 60                # 実際に高い力を出した負担
丈夫さ係数 k = 1 − 0.1 × (丈夫さ−100)/50   # 0.9〜1.1

体力減少 ΔC = clamp(k×(4 + 14e + 10w + 8h), 4, 55)
脚疲労増加 ΔB = clamp(k×(3 + 22 L_finish + 6j), 3, 45)
C_next = max(0, C−ΔC)
B_next = min(100, B+ΔB)
```

12,000J/kg等は消耗ゲージへ換算する基準で、レース距離や格式から逆算しない。W使用の脚への影響は既にLに入るので、ΔBへさらにwをそのまま足して二重に罰しない。jもLと一部重なるため、最初は小さく入れ、脚負担を過大にしないよう検証する。

次の出走での仮の影響は `W_start = Wmax×(0.75+0.25 C/100)`、`Amax_eff=Amax×(0.9+0.1 C/100)`、`L_start=0.25 B/100` から始める。脚の上限・走行コストへの影響はL側の既存式に任せ、Bでさらに同じ速度罰を重ねない。現行エンジンへは初期状態を渡す口の追加が必要。

回復力による休養1週の回復量は、体力 `12+8u_回復力`、脚疲労 `5+5u_回復力` 程度を初期案とし、休養方式で修正する。体力のほうが早く戻り、脚を使い切った後は連戦しづらい形を狙う。実際の週間ローテーションを作ってから数値を詰める。

「大きなレースほど消耗する」は強い相手・速い流れ・勝ちに行く指示によって実際の出力が増えることから表す。**同じ走りなら同じ消耗**。G1というラベルだけで消耗倍率を掛ける必要はない。大目標では、普段より小さい余力でゴールしてよい騎乗方針を選べるようにする。

## 9. 試走で確認できたことと限界

全結果と再現条件は [MAPPING_RESULTS.md](MAPPING_RESULTS.md)。

- 品質100・偏差なし・R=0で、瞬発側D=−1は1200m **53.44秒**、持久側D=+1は**56.64秒**。3600mでは**193.89秒対188.07秒**と逆転した。時間刻み0.05秒でも方向は変わらない。
- ランダム84羽ずつ、2品質帯×7距離の**1,176走がすべて完走**。Dと「1200mから3600mへの順位改善」の相関は品質70で**0.659**、100で**0.801**。距離の向きは集団でも出る。
- 品質100の1200m上位25%は平均D=−0.596、3600mでは+0.252。品質70では1200m上位が平均D=+0.045で、序盤の短距離選別は弱め。50下限による差の圧縮と、短距離でも心肺が重要な影響がある。序盤でも強い短距離専門性を求めるなら次の調整対象。
- Dだけを変えた同品質7羽は、1200〜2000mで瞬発端、2400〜3600mで持久端が勝つ。**中間型が各距離を独占する状態は、この一次の遺伝軸だけでは確認できていない**。まず4大分類の土台として使い、中間距離の勝者は品質の組合せ・R・個体差・コースを含む集団で育てる。距離ボーナスで無理に埋めない。
- Rを変え、同じ17m/sで道中を走らせるとラスト400mは持続型18.023秒、放出型17.661秒。発走から全力を要求した2400mは持続型124.260秒、放出型128.862秒。放出型は末脚が速く、早い全力の代償が大きい。
- 両R型とも詳細探索では巡航→スパートが最速。これは「逃げるより差す方が常に強い」証明ではない。単独走ではそもそも前後関係・進路・相手にペースを強いる利点がない。0.03秒程度の戦術差まで確定的な優劣とは扱わない。
- 身体8能力がそれぞれ50/150の全256隅×7距離でも**1,792走すべて完走**。疲労コストは正。平地での入力範囲の点検であり、馬場・心理・不調込みの検証ではない。

## 10. 次に実装・検証する順序

1. 本対応式で生成した個体を実験画面へ読み込めるようにする。品質・D・Rと8能力を変え、同じ物理モデルで確認する。
2. レース中の消耗履歴と、出走後のC/Bへの変換を実装。全力・温存・距離・疲労からの回復を数週間単位で比べる。
3. 根性・意欲・自制心の目標出力制御を導入。弱い根性が余力を残して緩め、高い根性でもWや力の上限を破らないことを確認する。
4. 相手を観測した賢さ・競り合い・羽混みを導入。同じ身体で性格だけを入れ替え、相性と戦術の勝率を比較する。乱数は対応する比較で共通にする。
5. コーナー・路面の物理を追加し、独立に条件を変えて適性を検証する。
6. 遺伝子の実際の継承と調教・成長を接続。初期から数世代の選抜で品質が上がり、D/Rの複数系統が残るか調べる。

集団走での合格条件は、前後の位置・仕掛けのタイミングを含む実際の走行から先行/差しを分類し、短距離/長距離×先行/差しの4群それぞれに、勝てる相手・流れ・性格の組合せがあること。自己最速だけでなく勝率、400mラップ、最終400m、W残量、L、出走後のC/Bを併記する。

賢さについては弱い相手なら同等の勝率で負担が減り、強い相手には必要な出力を使い、誤判断すれば取りこぼすことを確認する。性格と身体の組合せは2×2などの入れ替え比較を行い、特定の性格が全身体・全展開で唯一の正解になっていないか確認する。

## 11. 既存30能力からの移行方針

旧 `model.js` の1〜99と、新案の50〜150は意味も範囲も違う。セーブ移行を行うまでキーを使い回さない。特に旧 `speed` は巡航速度、試作の `speed` は最高速なので、単なる数値の拡大では対応しない。

| 旧能力 | 新案での扱い |
|---|---|
| 巡航速度・スタミナ・持続力・瞬発力・加速 | 心肺 / スパート容量 / 最高速 / 瞬発力へ意味を分けて再定義 |
| 燃費 | 走行効率へ |
| 脚部 | 脚持久力、疲労耐性、管理面の丈夫さへ分割 |
| ゲート・集中・自在・順応性 | ゲート習熟、賢さ、自制心などへ整理。万能な適性補正は付けない |
| 落ち着き・根性・羽混み・闘争心 | 対応する性格へ。走る意欲と賢さを追加 |
| 悪路・芝・ダート・バランス・コーナー | 遺伝的な接地の向き＋技能で表す |
| 登坂・耐風 | 物理の仕事・抵抗、姿勢・出力・効率で表す |
| 丈夫さ・回復力 | 管理用の資質として維持 |
| 早熟・長命 | 能力点ではなく年齢に対する成長曲線の特性へ |
| 学習力・度胸・耐暑など | 必要なら補助特性として残す。今回の8身体能力に無理に押し込まない |

## 12. 現実から借りる部分とゲーム上の仮定

- 距離に関係する遺伝的な体質を置く参考として、サラブレッドのMSTN周辺変異と距離適性を扱った研究がある。ただし本案のD/R・係数・品質群は独自の設計。[Rooney et al., 2018](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0205664)
- 性格を全部同じ遺伝率で扱わない参考として、702頭を対象に、恐怖反応・社会的反応・学習などで遺伝と環境の関わり方が異なると報告した研究がある。本案の寄与比率や「賢さ＝疲労を嫌う」はゲーム上の仮定。[Hausberger et al., 2004](https://pubmed.ncbi.nlm.nih.gov/15584780/)
- プールを主に有酸素寄りとする参考として、5頭の持久系アラブ馬の自由遊泳を測り、主に有酸素・最大下の運動とした研究がある。これだけから脚組織の長期適応や最適な調教量までは決められない。[Leguillette et al., 2024](https://pubmed.ncbi.nlm.nih.gov/39030565/)

実馬の距離適性・競走時計・怪我の予測を行うモデルではない。借りるのは仕組みの向きと有限な資源の考え方で、係数は実際のゲーム内分布とレースから調整する。
