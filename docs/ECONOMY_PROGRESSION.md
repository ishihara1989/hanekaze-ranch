繁殖牝羽の購入・売却は同じ評価式を使う。8身体能力・2管理資質・6性格の遺伝基礎値から発現中の欠点を引いた平均を `A` とし、遺伝評価を `3,000 × 10^((A − 76.7) / 12)` Gとする（遺伝評価部分の上限8,000万）。源流程度を約3,000 Gの基準とし、平均が12上がるごとに10倍になる。調教、学習した性格、生まれつきの個体差、現在の体調は価格に影響しない。

戦績評価は新羽勝ち12,000・未勝利勝ち10,000・1勝クラス勝ち40,000・2勝クラス勝ち150,000・3勝クラス勝ち600,000・オープン勝ち200万Gのうち最高額に、勝利数×5,000 G（10勝まで）を加算する。重賞勝者は上表の式へ置き換える。勝利条件の倍率は賞金と共通の距離・路面倍率で、ダート・短距離の実績は低めになる。

遺伝評価と戦績評価を足した額に適性倍率を掛け、100 G単位に丸める（最低1,000 G）。芝−ダート適性差に最大±6%、短距離傾向に最大−5%・長距離傾向に最大＋3%。右回り・左回り・直線適性はそれぞれ普通を基準に最大±4%、2クッション適性と3成長適性はそれぞれ最大±2%を乗算する。直線適性には苦手がないため、補正は0〜＋4%。

全クラスで2〜5着に1着賞金の40 / 25 / 15 / 10%を配分する。出走手当は全着順に1着賞金の3%を交付し、6着以下・未完走は手当のみ。本賞金と手当は整数Gに丸め、出走時に経費を一度だけ支払う。戦績には本賞金・手当・経費の内訳を保存する。過去の戦績と所持金は再計算しない。

## 自動出走の選び方

通常番組は新羽〜オープンの各クラスに毎週、芝1400 / 1800 / 2200 / 2400 / 3000m、ダート1400 / 1800 / 2200 / 2400mを用意する。既存の番組IDと重賞日程を残し、クラスごとに距離が1つに固定される問題を解消する。

重賞は[2026年の中央・地方番組](RACING_CALENDAR.md)を参考に年間179競走へ拡充。GⅠ37・GⅡ51・GⅢ91、ダート63競走、1400m以下40競走。地方のJpnⅠ/Ⅱ/Ⅲはゲーム内のGⅠ/Ⅱ/Ⅲへ統合する。追加GⅠは1億Gの下限を適用し、GⅡ/Ⅲは既存の賞金・距離・路面倍率を使う。下位重賞のNPCは路面・距離帯・年齢区分・牝羽限定で分け、ダートGⅠも新設の2・3歳／短距離／牝羽部門を分離する。出走間隔や自動出走の適性条件は共通。

12週先までの出走可能なレースを調べ、前走から4週以上空ける。候補の週の年齢・性別・勝利数条件を確認したうえで、距離因子の平均に従って次の範囲に絞る。

| 距離の傾向 | 候補にする範囲 | 目標距離 |
|---|---|---|
| 平均が−0.3未満（短距離寄り） | 1000〜1600m | 1400m |
| −0.3〜0.3（中間） | 1600〜2200m | 1800m |
| 0.3超〜0.65（長距離寄り） | 2200〜3600m | 2400m |
| 0.65超（長距離傾向が強い） | 2200〜3600m | 3000m |

芝・ダートの適性平均に0.15を超える差があれば、得意側のみを候補にする。候補のスコアは「目標距離との差÷800＋待機週数×0.13＋8×（1−接地効率）」で、小さいものを選ぶ。「重賞に挑む」は候補内の重賞から3を引くため、距離・羽場の条件を破って重賞を選ばない。「着実に勝つ」も出走予定週にオープンクラスの資格があれば重賞を検討する（2歳は1勝、3歳6月までは2勝、3歳7〜12月は3勝、4歳以上は4勝。オープン・重賞の勝者は資格を維持）。候補週の現在能力・体調・脚負担・性格・路面とコース適性を使い、全羽を同じ内枠から単走させた予測時計を比較する。最速の相手から1%以内なら優勝争いが可能とみなし、その重賞のスコアから2を引く。一般競走よりスコアが良く、経費を支払える重賞を優先し、見込みがなければ一般競走で勝ちを積む。5勝・平均能力80の固定条件は使わない。相手がまだ生成されていない場合は別の仮状態で予測用の出走羽を生成し、セーブや乱数を変更しない。予測には実戦の枠順・羽混み・競り合いを含めず、勝利を保証しない。実際の出走週には体力75以上、脚負担25未満、疾病なし、経費を支払えることを再確認する。

各週の出走先は他牧場の重賞処理前に一度決め、相手の生成や競走結果で同じ週の選択が揺れないようにする。出走しない週は体力85未満・脚負担15超・疾病ありなら休養し、それ以外は総合調教を行う。どちらの方針でもこの休養・調教ルールは同じで、8週予定で個別に指定した休養・調教・出走を優先する。

旧実装は全レースを同じスコアだけで比較していたため、重賞加点が不適距離を上回る場合があった。また未勝利・2勝・オープンは2200m固定で、短距離向きでも選択肢がなかった。

## 他牧場と種牡羽市場

ファイア、ブリザド、サンダラ、フレア、メテオ、アルテマの6牧場。遺伝品質の有利アレル頻度は順に .42 / .46 / .52 / .60 / .67 / .70。強い魔法の牧場ほど高能力になりやすいが、着順を直接保証する補正は使わない。

共通の集団レース物理でGⅠ37競走と選抜前哨戦17競走を背景で実走する（2026-10-04の週送り軽量化）。各GⅠ路線に牧場ごとの競走羽を生成し、その年は前哨戦も同一個体・同じ能力で戦う。牡羽10路線（短距離、ダート、マイル、中距離、長距離、3歳マイル・2000m・ダービー・長距離、2歳）と牝羽限定部門・若羽ダート等を分けて出走条件を守る。前哨戦は各路線で年1競走まで、年齢・性別・路面が合うGⅡ・GⅢから選ぶ。[選抜基準](RACING_CALENDAR.md)を参照。NPCは調教済み、毎年新しい競走世代を生成する。各世代は実際の父母から遺伝子を継承し、NPCの血統も多世代に伸びる。導入羽を端点とする血統、クロスと潜性の欠点は[配合拡張](INBREEDING.md)を参照。

条件戦と選抜外のGⅡ・GⅢは、自牧場が出走するときだけクラス相応の相手を6羽まで一時生成する。従来のクラス別遺伝品質・調教程度・物理を使い、生成用の乱数は競走単位で独立させる。GⅠ・前哨戦では主要牧場の継続個体が出走する。いずれも自牧場を含む12羽に満たない分は、低能力な一般参加羽で埋める。この補充羽の身体能力は50〜65の範囲とし、相手の各能力の最小値から15下げた値を上限にする（50が下限）。最低能力付近の新羽とも差が付くよう、身体能力から求めた巡航上限を80%、最高速を65%にする。性格は50〜65、羽場・コース適性は中間値。クラス相応の一時生成相手にはこの低能力補正を掛けない。着順の差し替えは行わず、同じ集団レース物理で走らせる。

低能力の補充羽は `filler-`、クラス相応の一時生成相手は `guest-` の競走単位IDを持ち、永続する `birds`、血統、年末表彰、種牡羽候補、繁殖牝羽セールには登録しない。保存するのは自牧場・主要牧場の戦績に含まれる出走名・時計・着順と、観戦に必要なスナップショットだけ。主要牧場の継続個体はGⅠ・前哨戦の実績を記録し、遺伝・配合・競走世代・市場選出を維持する。既存セーブの競走羽・血統・能力・過去の成績は削除・再抽選しない。

新規ゲームでは固定された世界シードで過去5年を実走し、GⅠ勝利記録のある牡羽を各年10羽、計50羽用意する。開業前の戦績は「開業○年前」で表示。毎年末に10羽を翌年から5年契約で登録。路線の異なる新しい勝者を優先し、候補不足時は未登録の過去勝者、契約終了の過去勝者の再供用で補う。架空の勝利数は付けない。供用が終わっても成績・血統は保持する。

繁殖牝羽セールには源流を父・不明を母とする未出走の3羽に加え、数万・数十万・数百万の遺伝能力帯ごとに芝中長距離寄り／ダート短距離寄りの未出走牝羽を各1羽、計6羽追加する。追加羽は他牧場の導入父母から実際に遺伝し、架空の戦績は付けない。前年度に競走引退した20歳未満の実際のGⅠ勝者、下位重賞勝者、重賞未勝利羽をそれぞれ最大4羽選び、最大21羽が並ぶ。標準シードの開業時は20羽、追加未出走羽は約3.7万〜5.4万／29万〜30万／314万〜401万G。

既存セーブの読み込み時には既存ロットを保持して不足分を追加し、未販売ロットだけ再評価する。購入済みの羽、所持金、遺伝子、戦績、配合の乱数は変更しない。翌年度には未販売羽を記録として残し、新しいロットへ入れ替える。

検索対象は名前・牧場・勝ったレース名。GⅠ勝利路線で絞り込み、料金・GⅠ勝利数・8身体能力・2管理資質・6性格・4羽場適性で並べ替える。ソートは生来の能力で比較する。

## 能力の公開と実績遺伝

初期から距離・脚質の傾向、身体／管理／生来性格を比較した長所2つ・短所2つを公開する。配合画面では父母双方、種牡羽の重賞勝利成績と出生補正も表示する。

共通評価は X：60未満、△：60〜80未満、◯：80〜100未満、◎：100〜120未満、☆：120以上。数値欄は切り捨てて評価境界と一致させる。0〜1の羽場・成長因子は表示のみ50〜150に換算し、物理や遺伝子そのものは変更しない。

2026-10-02更新：1歳以下は「成長率」として早い成長・遅い衰え始め・緩やかな衰えを5段階で表示する。2歳からは現在の身体8能力・管理2資質・性格6要素を5段階で表示する。判定は役割でなく競走年齢を使う。

繁殖担当の遺伝情報は個体詳細、配合の父母双方、セール各個体に表示する（セールは初期状態で折りたたむ）。能力品質・生来の性格・体質・出力配分・発現した欠点を合算した評価だけを公開し、基礎遺伝と補正の内訳は別表示しない。身体は遺伝品質＋筋・代謝構成Dの効果＋出力配分Rの効果−発現した全欠点、管理は品質−欠点、性格は遺伝因子平均−欠点。虚弱体質・気性難による間接効果も含める。調教、生来の個体差、GⅠ血統の出生補正は含めない。

遺伝評価はX：65未満、△：65〜80未満、◯：80〜95未満、◎：95〜110未満、☆：110以上。合算の数値は記念施設の一方から公開し、切り捨てた値とメーターを表示する。

| 施設 | 公開する情報 |
|---|---|
| 研究所なし | 年齢に応じた成長率／現在ステータス、ステータス遺伝の合算。評価記号のみ |
| 研究所 | 羽場・成長・羽色の遺伝、得意羽場・クッションなどの競走情報。評価は5段階 |
| 研究所＋GⅠ制覇 | 全遺伝の座位。品質32座位、性格、D/R、適性、成長、通常羽色、金因子、欠点の全因子 |
| 研究所＋記念館または銅像 | 全遺伝の数値・欠点因子の集計 |
| 研究所＋記念館＋銅像 | 全情報。現在能力・管理・性格・適性の数値とメーター、成熟時の伸びしろ、競走羽の体調・脚の負担・療養期間 |

座位は有利系がaa＝◯、aA（Aa）＝◎、AA＝☆、不利系がaa＝X、aA（Aa）＝△、AA＝◯。左から座位順に1座位1文字で表示し、品質32座位は32文字。配合では種類ごとに父を上・母を下に並べ、同じ座位を比較する。数値・羽色の因子は対で表示する。既に記念施設と研究所がそろったセーブでも座位表示を維持する。

記念館や銅像だけでは研究情報を解禁しない。遺伝の数値は一方の記念施設から、現在ステータスの数値は両方から公開する。

能力の遺伝品質は各能力32座位の二倍体因子から計算する。有利因子Aを1個あたり＋1.25として、品質＝50＋1.25×Aの総数。AAは1座位あたり＋2.5、Aaは＋1.25、aaは＋0で、ヘテロでも効く。これは出生時の乱数の中心に含める基礎値であり、「AAだけが乱数の後に加点する」仕組みではない。

欠点は品質とは別の座位。欠点座位のAAは正常、Aaは保因、aaは発現で、aa1座位あたり関連能力−2。身体は「基礎遺伝＋D/R補正＋出生乱数」を50〜150内に抽選した後で欠点分を減算し、再び50〜150に収める。管理は品質−欠点、性格は遺伝因子平均＋出生個体差−欠点。表示の変更はこの出生計算や既存個体の能力を変更しない。

`public/genetics-preview.html` は32羽の源流を選び、5公開段階を切り替えたり並べたりして確認する専用ページ。本体と共通の `ranch-observation.js` を使用し、現在ステータスの公開も確認できる。源流だけを固定カタログから生成し、セーブデータの読み書きと週送りは行わない。

出生時の身体能力の乱数幅は遺伝品質と距離・出力配分による中心から -20〜+20。正規乱数をtanhでこの範囲に連続変換し、血統補正で端点を移動する。遺伝子・学習した性格・調教値を書き換える効果ではない。

低い遺伝品質と筋・代謝構成が重なり、中心が身体能力の下限50を下回る場合などは、中心を50〜150内へ収めてからこの有限幅の抽選を行う。抽選結果自体を端点へ丸めず、長距離番組の相手羽生成で到達できない範囲を抽選し続け、週送りが停止する問題を防ぐ。
