# 序盤・経済・他牧場・実績遺伝（2026-09-30）

## 開業と資金の使い道

3月第1週、20,000 Gと2歳牝羽「ハネカゼノヒカリ」で開始する。瞬発力116・スパート容量108の短距離／差し寄り。モーグリの調教・休養・出走を登録済み。最初の繁殖牝羽購入と配合後、幼羽の成長中も初期競走羽が走る。

| 項目 | 金額（G） |
|---|---:|
| 源流の配合 | 600 |
| 未出走のセール繁殖牝羽 | 2,800〜3,200 |
| 新羽〜オープンの1着賞金 | 900〜2,600 |
| GⅢ / GⅡの1着賞金 | 1,500万 / 4,000万 |
| GⅠの1着賞金 | 1億〜1億8,000万 |
| ダート・1200mのGⅠのみを勝った種牡羽 | 30万〜100万 |
| その他のGⅠ勝者の配合 | 300万＋GⅠポイント×10万、上限8,000万 |
| GⅡ・GⅢ勝ちの繁殖牝羽 | 1,000万＋重賞勝利数×500万 |
| GⅠ勝ちの繁殖牝羽 | 1億＋GⅠポイント×100万 |
| 研究所 | 建設500万（拡張なし） |
| 他の施設の基準建設費 | 800万〜1億 |

研究所はレース初勝利で解放する。建設するとステータス以外の遺伝と得意羽場などを公開する。記念館か銅像の一方で全遺伝の座位、両方で現在能力の数値を含む全情報を公開する。研究所だけを拡張して公開段階を進める方式は廃止。旧セーブの研究所Lv.2〜3は保存したまま、公開判定では建設済みとして扱う。全施設とも開始資金だけでは購入できない。

通常賞金は維持費と次の出走・源流配合を賄う水準。週の基本費12 G、競走羽20 G、幼羽4 G、繁殖羽8 G、施設段階ごと2 G。重賞の2〜5着にも40/25/15/10%を配分し、勝利へ向けた設備投資の資金になる。

## 他牧場と種牡羽市場

ファイア、ブリザド、サンダラ、フレア、メテオ、アルテマの6牧場。遺伝品質の有利アレル頻度は順に .42 / .46 / .52 / .60 / .67 / .70。強い魔法の牧場ほど高能力になりやすいが、着順を直接保証する補正は使わない。

共通の集団レース物理で重賞を実走する。各路線に牧場ごとの競走羽を生成し、その年は同一個体・同じ能力で戦う。牡羽10路線（短距離、ダート、マイル、中距離、長距離、3歳マイル・2000m・ダービー・長距離、2歳）と牝羽限定部門・下位重賞を分けて出走条件を守る。NPCは調教済み、季節ごとに新しい競走世代を生成する。各世代は実際の父母から遺伝子を継承し、NPCの血統も多世代に伸びる。導入羽を端点とする血統、一般競走の相手、クロスと潜性の欠点は[配合拡張](INBREEDING.md)を参照。

新規ゲームでは固定された世界シードで過去5年を実走し、GⅠ勝利記録のある牡羽を各年10羽、計50羽用意する。開業前の戦績は「開業○年前」で表示。毎年末に10羽を翌年から5年契約で登録。路線の異なる新しい勝者を優先し、候補不足時は未登録の過去勝者、契約終了の過去勝者の再供用で補う。架空の勝利数は付けない。供用が終わっても成績・血統は保持する。

繁殖牝羽セールには源流を父・不明を母とする未出走の3羽に加え、前年度の実際のGⅠ勝者2羽と下位重賞勝者2羽を最大数として並べる。

検索対象は名前・牧場・勝ったレース名。GⅠ勝利路線で絞り込み、料金・GⅠ勝利数・8身体能力・2管理資質・6性格・4羽場適性で並べ替える。ソートは生来の能力で比較する。

## 能力の公開と実績遺伝

初期から距離・脚質の傾向、身体／管理／生来性格を比較した長所2つ・短所2つを公開する。配合画面では父母双方、種牡羽の重賞勝利成績と出生補正も表示する。

共通評価は X：60未満、△：60〜80未満、◯：80〜100未満、◎：100〜120未満、☆：120以上。数値欄は切り捨てて評価境界と一致させる。0〜1の羽場・成長因子は表示のみ50〜150に換算し、物理や遺伝子そのものは変更しない。

2026-10-02更新：1歳以下は「成長率」として早い成長・遅い衰え始め・緩やかな衰えを5段階で表示する。2歳からは現在の身体8能力・管理2資質・性格6要素を5段階で表示する。判定は役割でなく競走年齢を使う。

繁殖担当の遺伝情報は個体詳細、配合の父母双方、セール各個体に表示する（セールは初期状態で折りたたむ）。能力品質・生来の性格・体質・出力配分・発現した欠点を合算した評価だけを公開し、基礎遺伝と補正の内訳は別表示しない。身体は遺伝品質＋筋・代謝構成Dの効果＋出力配分Rの効果−発現した全欠点、管理は品質−欠点、性格は遺伝因子平均−欠点。虚弱体質・気性難による間接効果も含める。調教、生来の個体差、GⅠ血統の出生補正は含めない。

遺伝評価はX：65未満、△：65〜80未満、◯：80〜95未満、◎：95〜110未満、☆：110以上。合算の数値は記念施設の一方から公開し、切り捨てた値とメーターを表示する。

| 施設 | 公開する情報 |
|---|---|
| 研究所なし | 年齢に応じた成長率／現在ステータス、ステータス遺伝の合算。評価記号のみ |
| 研究所 | 羽場・成長・羽色の遺伝、得意羽場・クッションなどの競走情報。評価は5段階 |
| 研究所＋記念館または銅像 | 全遺伝の数値・座位。品質32座位、性格、D/R、適性、成長、通常羽色、金因子、欠点の全因子 |
| 研究所＋記念館＋銅像 | 全情報。現在能力・管理・性格・適性の数値とメーター、成熟時の伸びしろ、競走羽の体調・脚の負担・療養期間 |

記念館や銅像だけでは研究情報を解禁しない。遺伝の数値は一方の記念施設から、現在ステータスの数値は両方から公開する。

能力の遺伝品質は各能力32座位の二倍体因子から計算する。有利因子Aを1個あたり＋1.25として、品質＝50＋1.25×Aの総数。AAは1座位あたり＋2.5、Aaは＋1.25、aaは＋0で、ヘテロでも効く。これは出生時の乱数の中心に含める基礎値であり、「AAだけが乱数の後に加点する」仕組みではない。

欠点は品質とは別の座位。欠点座位のAAは正常、Aaは保因、aaは発現で、aa1座位あたり関連能力−2。身体は「基礎遺伝＋D/R補正＋出生乱数」を50〜150内に抽選した後で欠点分を減算し、再び50〜150に収める。管理は品質−欠点、性格は遺伝因子平均＋出生個体差−欠点。表示の変更はこの出生計算や既存個体の能力を変更しない。

`public/genetics-preview.html` は32羽の源流を選び、4公開段階を切り替えたり並べたりして確認する専用ページ。本体と共通の `ranch-observation.js` を使用し、現在ステータスの公開も確認できる。源流だけを固定カタログから生成し、セーブデータの読み書きと週送りは行わない。

出生時の身体能力の乱数幅は遺伝品質と距離・出力配分による中心から -20〜+20。正規乱数をtanhでこの範囲に連続変換し、血統補正で端点を移動する。遺伝子・学習した性格・調教値を書き換える効果ではない。

父母を深さ0、曽祖父母の親まで深さ3として4世代を参照。各祖先の性別で、牝羽は下限、牡羽は上限を上げる（父側・母側の分岐では判定しない）。勝利ごとに下表の重み×GⅠポイント/100×0.5^深さを加算。各端点の上昇は最大12、最終能力は50〜150。同じ祖先は最も近い位置で一度だけ参照し、近親による重複加算を防ぐ。
