# v4 集団レース

プレイヤーは配合・調教・休養・出走予定を整え、育てたチョコボを信じて送り出す。レース中のペース・スパート・進路はチョコボ自身が能力・性格・周囲の状況から判断する。観戦の再生速度やカメラは走りと結果に影響しない。

`ranch-race.js` が全12羽を共通の時刻で進める。`ranch-engine.js` の `race()` はこの結果で着順・賞金・出走後の消耗を精算する。`simulateBird()` は同じモデルの単独走で、身体能力を調べる実験用の `RacePhysics.simulate()` は従来どおり性格・隊列の影響を含まない。

## 隊列と判断

0.2秒ごとに全羽の更新前の位置と速度を取得し、全員が同じ隊列を見て判断する。配列の先頭から更新しても後の羽が有利にならない。乱数は使わず、出走羽・能力・状態・馬場が同じなら同じ結果になる。

- 前後距離と横位置から12m以内の密集度で羽混みを、6m以内の最も近い相手で競り合いを判定。距離が離れるにつれて連続的に弱まる。1対1の並走は競り合いであり、羽混みにはしない。
- ゲート直後の横並びを羽混みと扱わないよう、発走から40mの間に効果を徐々に有効化する。
- ゴール済みの羽は競り合い・羽混みから除外する。ただし、その後ろの羽が「勝てるリード」と判断することはない。

横位置はゲート番号とは別に、0〜11の連続値で保持する。横移動は毎秒0.7レーン（約2.9m）までとし、発走直後は実際に進める距離の範囲に制限する。`race-course.js` の共通コース形状を使い、外周の弧長と斜行距離を走行距離として支払う。左右回り・直線とコーナーの境界・複数周回に同じ計算を使う。

各進路候補について、内側で節約できる弧長、横移動量、前の羽に追いついて失う距離を比較する。通常は3〜5秒先、最終コーナーの100m手前から最後の直線までは5〜9秒先を見る。賢さが高いほど先を読む。前方が遅く、追いつく時点で隣の進路も塞がる候補には追加の不利を付け、コーナー出口で追い越せる位置を早めに選ぶ。最終直線では内寄せを優先せず、進路が空いた時点の横位置を維持する。追い抜いた後も内側へ戻らず、新たに前が塞がった場合だけ進路を選び直す。

横移動の途中で相手を横切る候補は採用しない。全羽が同時に動いて進路が交差する場合は両方の横移動を止める。前が塞がる場合は追従速度を要求し、減速だけでは安全な間隔を保てないときは前の羽をすり抜けないよう位置と速度を制限する。空く進路がないときは待つため、閉塞の完全な回避や外枠の損失ゼロを保証する方式ではない。

## 性格の作用

性格は50〜150を0〜1に換算して使用する。身体の最高速・推進力・有酸素供給量・容量を増やす補正は加えない。

| 性格 | 実装した挙動 |
|---|---|
| 根性 | 疲労を感じても自分から走りを緩めにくい。残す無酸素容量の下限を12%から2%へ下げ、疲れた競り合いで目標速度を最大2.5%押し上げる。出力不足なら加速できず、消耗は実際に支払う |
| 走る意欲 | 疲労を嫌って緩めにくい。自制心が低いと道中の目標ペースを最大2.5%上げる |
| 自制心 | 道中の飛ばしすぎを抑え、競り合いによる闘争心の反応を最大65%抑える |
| 羽混み耐性 | 密集による最大7.5%の目標速度低下と、最大10%の余計な運動コストを軽減する |
| 闘争心 | 接近した相手に反応し、目標速度を最大4.5%上げる。一方で運動コストも最大7%増える。高いほど必ず速くなる性質ではない |
| 賢さ | 羽混み・競り合いで生じる余計な運動コストを最大80%抑える。安全な先頭では目標速度を緩めて余力を温存。疲労を避ける従来の傾向も維持 |

賢さによる温存は200m通過後、後続に12mを超える差があるときだけ働く。差が36mに達するまで徐々に強まり、残距離と後続の最大速度から、ゴールまで12mの差を保つ目標を毎ステップ計算する。巡航速度の85%を下限とし、差が縮む、後続が加速する、先頭でなくなる場合は通常のペース判断へ戻る。これは現在の隊列からの判断であり、勝利を保証する未来予測ではない。

## コーナー・直線適性

回転方向に対応する右回り・左回り適性でコーナーの目標速度低下と余計な運動コストを軽減する。普通でも曲がるために減速し、得意でも減速は残る。半径160mでは苦手10%・普通6%・得意2%の目標速度低下で、小回りほど強い。性格の賢さ・自制心とは別の遺伝要素で、性格の作用と重ねて減速を増やさない。

直線適性には苦手がなく、普通には追加効果がない。得意では直線の目標速度・速度上限が最大2%伸び、コーナーから出た直後の最大推進力が最大4%増える。推進力のボーナスは出口から60mで消える。発走が直線の出口近くでも、実際にコーナーを通過するまでは推進力を増やさない。セクションが変わっても速度を瞬時に書き換えず、既存の加減速で追従する。

有酸素供給や予備容量は増やさず、余分な推進力の筋仕事は通常どおり支払う。適性の詳細と32源流の配分は [GENETICS.md](GENETICS.md)、[ROOT_STALLIONS.md](ROOT_STALLIONS.md) を参照。

## 消耗・結果・保存

余計な運動コストは `RacePhysics.step()` の `effortCost`（既定値1）で筋仕事に掛ける。有酸素出力を増やさず、足りない仕事は無酸素容量から支払う。実際の消費エネルギー・無酸素使用・脚疲労は、従来の出走後の体力と脚負担にも反映する。

出走後の体力低下・脚負担の増分には、距離と芝・ダートの消耗倍率も掛ける。芝1800mを1として、芝1400m以下0.8、芝2000〜2400mは1.15、芝2500〜2600mは1.25、芝2800m以上は1.4。ダートは同距離の芝の0.8倍。丈夫さによる軽減と、走行中の実際の消費量も引き続き作用する。倍率はレース後の管理に適用し、走行物理の速度や着順への補正には使わない。賞金・経費との対応は[経済バランス](ECONOMY_PROGRESSION.md)を参照。

ゴールをまたいだステップでは時刻だけでなく、容量・脚疲労・累積消費エネルギーもゴール地点へ補間する。900秒で打ち切った場合は未完走とし、完走羽の後に進んだ距離順で並べる。

トレースには前後・横位置、実走距離、速度・余力・疲労・行動を保持する。通常の2秒間隔に加えて横移動の開始・停止・速度変更を記録し、再生時の進路を補間する。結果には羽混み・競り合い・温存・閉塞の時間、横移動量、距離ロスと余計に使ったエネルギーの集計 `interactions` を保存する。旧v4戦績にはこの任意項目がなくても読み込める。過去の戦績は再計算しない。

## 検証

`node --test tests/ranch-race.test.cjs tests/race-routing.test.cjs` で単独走と密集の違い、各性格の効果・交換条件、温存解除、コーナー前の内寄せ、最終コーナーの進路確保、閉塞時の待機、全ステップの間隔、出走順不変、入力非変更、完走補間、タイムアウト、実際の牧場モデルとの接続を確認する。既存の育成・馬場・精算・保存の回帰検証も継続する。係数はゲーム用の仮設定で、多世代のGⅠ難易度の最終調整は別途行う。
