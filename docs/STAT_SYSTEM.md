## 遺伝・上限・現在値

各能力は独立した1組の対立遺伝子を持ちます。父と母からそれぞれランダムに1つずつ継承し、aa = 40 / Aa・aA = 62 / AA = 84 を遺伝基礎値とします。

**能力上限 = 遺伝基礎値 + 誕生時に決める個体差**

- ♂：−3〜＋7の整数を等確率で抽選。
- ♀：−3〜＋3の整数を等確率で抽選。
- 30能力それぞれで独立に抽選し、保存後・再読み込み後も固定。
- 次世代に受け継ぐのは遺伝子。親の調教結果と個体差は継承しない。
- 能力の表示域は1〜99。現在の遺伝モデルでの最大上限は♂91、♀87。
- 配合予測の範囲は最小〜最大であり、間の値がすべて出るわけではない。

幼鳥の現在値は `floor(上限 × 0.55)` から始まります。最初の6羽と対戦相手は約85%まで育った状態です。調教と2歳までの自然成長で、現在値を上限まで伸ばせます。上限は調教で変わりません。

## 調教・成長・維持

1歳から競走引退まで、週1回、6種の専門メニュー（各5能力）または全30能力の総合メニューを実行できます。1能力に絞る重点調教も選択可能です。

- 基本成長量：`round(2 + 学習力×0.04 + 若齢補正)`。若齢補正は4歳未満なら `早熟×0.035`。
- 総合調教は基本値の0.4倍、重点調教は1.5倍。最低1、残り成長幅まで。
- 2歳まで：4週ごとに `1 + floor(早熟 / 35)` ずつ全能力が自然成長。
- 維持期の目安：`192 + round(長命×1.1)` 週齢（約4〜6歳）。
- 維持期を過ぎると8週ごとに、長命以外の育成分が1ずつ低下。遺伝子・個体差・上限は変化せず、再調教で回復可能。
- 週回復：調子 `15 + round(回復力×0.25)`、脚負担 `10 + round(回復力×0.3)`。
- 脚負担70以上では出走・調教不可。次の週へ進めると回復。永久的な故障や死亡は未実装。

## レース

ゲート反応 → 加速 → 巡航 → スパートを個別に計算します。スパート速度と持続時間、そこに達する加速力は別の要素です。作戦はプレイヤーの鳥に適用し、相手は一定ペースを基準に各自の気質で走ります。

4つの競羽場と年間番組で、芝・ダート・良／重・坂・向かい風・暑さを組み合わせます。前後24m以内に相手がいる場合に羽混み、近接した相手との競り合い・追走を判定します。実際の進路選択や接触はなく、隊列による補正を表す簡易モデルです。

数値はゲームバランス調整用の初期設定です。能力ごとに効果を独立して変更できるよう、`model.js` にまとめています。
