## 現在遊べる範囲

配合・育成・競走・売買を通じて、複数世代の牧場経営を進めるブラウザゲームです。1年は48週で、プレイヤーと競合6羽主が同じ世界の個体を所有します。

- 新規開始は12,000 G、競走羽4羽、繁殖羽2羽。競合は各24羽、合計144羽。
- 幼羽を育成し、2歳から競走に出走。収得賞金によってクラスが上がります。
- 6競羽場、毎週の条件戦、年間27重賞。GⅠは現在のJRAの時期に合わせ、『チョコボスタリオン』の競走名を使っています。
- レースは直線・コーナーのある2D周回路で観戦でき、再生速度変更・結果までのスキップが可能です。
- 基本は週送りだけで進みます。自分で調教しなかった羽は週送り時に調教され、出走予定の週に競走します。出走週は観戦か結果のみかを選び、月が変わると月次まとめを表示します。
- 新規開始時はリナ調教師と専属契約した自動運営です。手動モードに切り替えると、出走は番組表からの予約か今週の即時出走で行います。
- 飼料・維持・調教師・競走の費用を、賞金・出走手当・売買・種付け料などでまかないます。
- 種付けから4週で出産。血統・遺伝子を引き継ぐ次世代を育成できます。
- 売却後も同じ個体が世界に残り、所有者・戦績・血統を追えます。

用語は羽主・競走羽・種牡羽・繁殖牝羽など、競馬の用語の「馬」を「羽」に置き換える方針です。コード内部の識別子は英語です。

## 実行環境とファイル構成

HTML・CSS・JavaScriptのみの構成で、ビルドや外部パッケージのインストールは不要です。Node.js のサーバーは静的ファイルを配信するだけで、ゲーム進行・保存はブラウザで行います。

```powershell
node server.cjs
```

起動後に `http://127.0.0.1:4173` を開きます。`PORT` 環境変数でポート変更が可能です。

| ファイル | 責務 |
|---|---|
| `public/index.html` | 起動ページ。model → world → world-views → game の順に読み込む |
| `public/js/model.js` | `RanchModel`。能力・遺伝・調教・加齢・レース物理・コース位置計算 |
| `public/js/world.js` | `RanchWorld`。羽主・番組・出走資格・結果精算・取引・繁殖・会計・週進行 |
| `public/js/world-views.js` | `WorldViews`。番組表・市場・調教師・経営・競合・成績などのHTML生成 |
| `public/js/game.js` | 全体状態の保持、画面操作、個体詳細、配合予測、観戦アニメーション、保存・読込 |
| `public/css/style.css` | 画面レイアウト、レスポンシブ表示、競走表示 |
| `server.cjs` | 指定された静的ファイルだけを127.0.0.1へ配信。キャッシュ抑止 |
| `tests/` | Node.js組み込みテストによるモデル・世界・UI連携の検証 |

`model.js` と `world.js` はDOMに依存せず、ブラウザでもNode.jsのテストでも利用できます。UIは画面ごとのHTMLを組み立て直し、イベントを `game.js` で受け取る方式です。羽の絵や背景はSVGで描画しています。
以降、本文中の `model.js`・`world.js`・`world-views.js`・`game.js` は `public/js/` 内、`style.css` は `public/css/` 内のファイルを指します。

## 能力・育成・配合

フィジカル21、性格9の計30能力を持ちます。各能力の基礎値は `aa=40 / Aa=62 / AA=84`。父母から一つずつ遺伝子を継承し、誕生時に♂−3〜＋7、♀−3〜＋3の整数個体差を加えて上限を決めます。

現在値は `floor(上限×0.55) + 育成分` を上限で制限した値です。親の育成分・個体差は直接遺伝しません。能力と別に距離適性・羽色の遺伝子も継承します。

1歳から競走引退まで週1回調教でき、専門6メニュー・総合・1能力の重点調教があります。調教は調子を消費し、脚負担を増やします。若齢の自然成長、毎週の回復、維持期を過ぎた育成分の低下も `model.js` が処理します。

配合画面は組合せから予測範囲・確率を表示します。近縁の表示はありますが、近親交配の能力低下や疾病などは未実装です。個別能力と数式は [STAT_SYSTEM.md](STAT_SYSTEM.md) にまとめています。

## 競走の登録から精算まで

1. `calendar(week)` が、その通算週の条件戦と重賞を生成します。イベントIDは通算週を含み、翌年の同名競走とは別IDです。
2. `eligibility` / `canEnter` で年齢・性別・クラス・調子・脚負担・資金・出走済みかを確認します。
3. `field` が永続するNPC個体から相手を選びます。最大6羽、自牧場は1競走1羽。2羽未満では成立しません。
4. `prepareRace` が出走料を計上し、出走情報と乱数種を `pendingRace` に記録。UIが保存します。
5. `makeRunners` が競走用状態を作り、`RanchModel.stepRace` が0.1秒刻みで進めます。
6. `finishRace` が順位・時計・本賞金・収得賞金・出走手当・戦績・消耗を反映し、結果を記録して `pendingRace` を解除します。同一イベントの二重精算を防ぎます。

観戦は `requestAnimationFrame` で表示しますが、計算は固定刻みです。1/2/4/8倍速、スキップ、自動競走は同じ走行モデルを利用します。競走用状態には距離・速度・体力・ゲート待機・スパート時間などがあり、永続する個体データとは分けています。

走行はゲート反応、加速、巡航、スパートを計算し、距離適性・羽場・坂・風・暑さ・気質・隊列などを補正します。距離はm、速度はm/sで扱い、画面ではkm/hと走破時計を表示します。

コースは直線2本と半円2つの簡易形状です。`trackPosition` を描画とコーナー判定で共用し、競走距離からスタート位置を逆算します。表示上の横ずれは羽を見分けるためのもので、実際の進路取りや外を回る距離損は扱いません。

## 1週進めるときの処理順

`RanchWorld.nextWeek` は、表示中の週を処理してから次週へ移ります。未精算の競走がある場合は進めません。

1. `dueEntries` が今週の出走予定を確認し、条件を外れた予定を取り消します。登録羽不足で不成立なら同じ週の別競走へ振り替えます。残った予定（UIで観戦しなかったもの）を結果まで計算。
2. まだ結果が出ていない今週の番組を、NPC所属羽で実施。
3. NPCと自牧場の羽を調教。自牧場は手動で調教済みの羽を除き、手動モードとリナは指定メニュー、他の調教師は育成余地で選択。当週に出走済み、繁殖羽、若すぎる個体、調子や脚負担の条件を満たさない個体は除外。
4. 現在の週の飼料・維持・給与・利息を計上。NPCにも簡易経費を計上。
5. 今週が年10週ならNPCの繁殖、4週ごとならNPC間の取引を検討。
6. 通算週を1増やし、各個体の加齢・回復・自然成長・衰えを処理。
7. 出産予定を迎えた母から産駒を生成し、野生帰還・2歳デビュー・競走引退を判定。
8. 過ぎた・所有外の出走予定を整理し、自動運営なら `planRaces` で4週先までの予定を補充。
9. ニュースと週次集計を更新。

`game.js` の `progressWeeks` は、この処理を1週ずつ呼んで保存・画面更新します。各週の前に `dueEntries` で出走予定を確認し、あれば「今週の出走」で選択を待ちます。観戦した競走は通常の観戦と同じく `prepareRace` → `finishRace` で精算され、その予定は消えます。「まだ進めない」は週を進めずに終了し、残りの予定は保持します。月をまたいだ場合は、終了時に月次まとめを開きます。4週・48週送りでも途中停止できます。新たな経費不足で借入・未払金が増えた場合は停止します。既存の借入があるだけでは停止しません。

## 他牧場・調教師・経営

NPCは仮の対戦相手ではなく、所有個体・資金を持つ6羽主です。出走・調教・繁殖・売買・引退を継続します。ただし意思決定は条件判定と並べ替えによる簡易AIです。

- NPCの調教は、育成余地の大きい専門メニューを優先。
- 年10週に各牧場最大3牝羽の繁殖を検討。幼羽が8羽以上なら控えます。
- 種牡羽は成績順を基本に選び、資金・年齢・空きなどの条件を確認します。
- 4週ごとに売り出し個体1羽についてNPC間取引を検討。
- プレイヤーは18羽房。受胎中は出産予定の1羽房を追加予約。
- NPCの取引・繁殖の収容判定には180羽を使用。長期の繁殖在籍を支えるための暫定値です。

調教師は3人です。リナは指定メニュー、セドリックとマーヤは育成余地に応じたメニューを選びます。自動運営では各羽に4週以内の出走予定を1つ保つよう編成し、前走・他の予定から通常3週以上、マーヤは4週以上の間隔を空けます。今週分の編成は調子75%以上・脚負担35未満が条件で、出走週に調子60%未満・脚負担50以上なら回避します。先の週は、条件に合う他牧場の羽が2羽以上いる競走から選びます。手動モードでは契約を保持したまま給与を止め、調教師が組んだ予定を取り消します。

経費不足は未払金に振り替え、所持金は0未満にしません。融資は最大5,000 Gずつ、借入枠20,000 G。経費不足による未払金でこの枠を超えることはあります。借入・未払金に週0.2%の利息がかかり、破産による強制終了はありません。

NPCの経費は一律の簡易計算で、プレイヤーと同じ債務・再建処理はありません。現状のNPC資金は負になる場合があります。市場価格・種付け料・賞金・経費の詳細は [WORLD_SYSTEM.md](WORLD_SYSTEM.md) を参照してください。

## 繁殖と一生

年齢は週齢から算出し、1月に一斉加齢する方式ではありません。

| 年齢・条件 | 現在の挙動 |
|---|---|
| 0〜1歳 | 幼羽。1歳から調教可能 |
| 2歳 | 競走羽へ移行 |
| 4〜6歳で重賞1勝または通算4勝以上 | NPC、および自動引退を任された自動運営羽は繁殖入り |
| 手動引退 | 競走羽から繁殖羽へ。競走復帰の操作はない |
| 10歳 | 競走羽はすべて引退 |
| 3〜30歳の繁殖羽 | 種付けに利用可能 |
| 31歳 | 野生へ帰還。経費対象外となり、血統記録は残る |

母を所有する羽主が種付けを行い、管理費200 Gと外部種牡羽の種付け料を支払います。受胎は必ず成立し、4週後に出産します。出産が31歳以降になる種付けはできません。

産駒の性別・遺伝子・個体差は保存した乱数種を使って生成します。出生時の母の羽主が産駒を所有し、生産牧場として記録されます。受胎中の母を取引すると、その所有者変更が出生時の所属にも反映されます。

## 保存・読込・互換性

- 保存先はブラウザの `localStorage`、キーは `hanekaze-ranch-v1`。キー名は旧名ですが、内部の `version` は3です。
- URLのホストやポートが違えば別の保存先です。`localhost` と `127.0.0.1` の保存は共有しません。
- v1/v2は `RanchWorld.migrate` と `RanchModel.migrate` で移行。旧能力・年齢を変換し、NPC世界を追加して、一度だけ6,000 Gの準備金を加えます。
- 通常起動時の旧保存は `hanekaze-ranch-v1-before-v3` に予備保存します。JSON読込は別経路で、現在の世界を置き換える確認があります。
- JSON読込は5,000,000バイト以下を受け付け、形式・参照・値などを検証します。
- 競走中断時は途中フレームを再開するのではなく、保存した登録情報と乱数種から同じ競走を計算して精算します。
- 保存データを読めない場合は、起動直後の上書きを避けて仮の牧場を表示します。ただし、その後の操作で保存すると同じキーを使用します。
- 保存失敗時は通知し、JSON書出を案内します。クラウド保存や複数タブ間の同期・排他制御はありません。
