# 年間重賞番組（2026年参考）

2026-10-04更新。ゲーム内は48週・6競羽場、出走上限9歳。実日程の月と季節を4週/月へ圧縮し、競走名と開催場をゲームの世界へ置き換えた番組です。実在番組をそのまま再現するものではありません。

## 規模と参考資料

- 中央平地：GⅠ24・GⅡ38・GⅢ68、計130。参考：[JRA 2026年度重賞競走一覧](https://www.jra.go.jp/keiba/program/2026/pdf/jusyo_2.pdf)、[2026年重賞日程](https://www.jra.go.jp/datafile/seiseki/replay/2026/jyusyo.html)。障害競走は含めません。
- 地方交流：46。参考：[JRA 2026年度地方競馬ダート交流重賞一覧](https://www.jra.go.jp/keiba/program/2026/pdf/bangumi/kouryu.pdf)、[NAR 2026年ダートグレード年間一覧](https://www.keiba.go.jp/dirtgraderace/2026/racelist/index.html)。JpnⅠ/Ⅱ/Ⅲはゲーム内でGⅠ/Ⅱ/Ⅲに統合します。
- 元の独自重賞3競走（ダイヤモンドダスト杯、コスタ・デル・ソル杯、王宮大賞典）を加え、**年間179（GⅠ37・GⅡ51・GⅢ91）**。
- **ダート63**、**1400m以下40（芝・ダート合計）**。地方の1200〜1500m戦、3歳ダート三冠、牝羽・2歳ダート戦を含みます。芝／ダート1600m以下の古羽混合戦は、年間の開催間隔が最大8週以内になる構成です。

## 保存・進行・表示

元の27競走は開催週、名称、条件、週内順序を保持します。追加は元の番組の後ろへ配置し、既存の `stakes` / `stakes2` IDが指す競走を変えません。翌年以降も同じ番組が繰り返され、既存セーブから追加競走を選べます。開催済みの過去結果を後から書き換えません。

自動出走は従来の適距離・羽場・4週間隔・体調・資金・方針判定を使います。新UIの出走資格は全重賞で2勝以上。下位重賞NPCを路面・距離帯・年齢・牝羽限定別に編成し、若羽ダート戦にも実際に相手が集まるようにします。全重賞を他牧場も実走し、勝者の実績・市場・表彰へ接続します。

牧場手帳の「予定」に年間重賞表を表示し、格と路線で絞れます。出走指定は各チョコボの8週予定から行います。GⅡ/Ⅲの賞金、GⅠポイント、レース物理は既存ルールを使用。追加GⅠの1着賞金は既存の未個別設定時の下限1億Gです。

重賞増により保存するNPCと競走成績、初回生成・週送りの処理量も増えます。NPCの成績と血統を維持し、保存時は従来の遺伝子圧縮・出走結果の共通化を使います。UTF-8で測ったセーブ容量は新規開始で約5.8MB、6年進行で約12.5MB。回帰テストは新規8MiB以内、6年時点でバックアップ読込上限20MiB以内を確認します。
