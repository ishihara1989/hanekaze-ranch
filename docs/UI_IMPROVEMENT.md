# UIの課題と改善方針

2026-10-04。実際のプレイ（新規開始 → セール → 配合 → 週送り → 誕生 → 観戦 → 2歳登録）で確認した課題と、改善の方針・進め方のメモ。

## 前提：ゲームの重心

- 中心は配合。序盤の大半は「出走回数を稼いで資金をやりくりする」「配合する」「誕生した子をセーブ・ロードで厳選する」の繰り返しになる。
- レースは回数が多い。観戦や演出に時間をかけさせない。飛ばせない演出を入れるとしても、GⅠなど重要なレースに限る。
- UIは「週送り」「配合の判断」「誕生結果の確認とやり直し」を速く・見やすくすることを優先する。

## 課題（要約）

| 分類 | 内容 | 例 |
|---|---|---|
| 状態が見えない | ホームに自分のチョコボ・予定・体調がなく、コピーと案内文が中心 | キャッチコピー、毎週同じ案内をするシロマ |
| 報告の装飾 | 手紙1通ごとに英字見出し・日付・差出人・切手・立ち絵。並びが重要度順でない | 「1年 3月 第1週 〜 1年 3月 第1週」、誕生が月報の下 |
| 説明・仕様の露出 | 計算式・配点・公開段階、UI自身の説明、開発中の言葉 | 「ゲージ全体は能力150…」「従来どおり抽選」「地方交流参考」 |
| キャラの使い方 | キャラがルールを読み上げる。モーグリ名義の文がシロマ口調 | 「4週以上の間隔を空けるクポ」 |
| トーン | 英字見出し約30種と詩的なコピー。雑誌・ブランドサイト調で、FF風のアートと合わない | OUR LITTLE RANCH、「小さな羽音から、物語はつづく。」 |
| 重複・不要 | 同じ情報が2〜3回。0件の表示や役割に無関係な欄 | 「重賞勝利はまだありません」、走っていない源流の「0戦0勝」 |
| 読みにくさ | 12px以下の文字が多い。補足文のコントラストが2.6〜3.7:1 | `font-size` 指定の約8割が12px以下 |
| 操作 | 種牡羽を選ぶ前に配合ボタンが押せる。観戦の操作が約20個並ぶ。命名が長いモーダルの途中にある | |

## 方針

1. 説明ではなく状態を見せる（文章ではなく数値・アイコン・ゲージ・バッジ）。
2. キャラは出来事に反応するだけにする。ルールは折りたたみかヘルプへ。解放・不足などのシステム通知は台詞と分ける。
3. 1つの情報は1か所に1回。0件の表示は出さない。
4. 繰り返す操作（週送り・配合・誕生の確認・ロード）を短く速く。特別な演出は大きな出来事だけ。
5. 英字の飾り見出しとキャッチコピーは使わない。アート（施設の絵・競走場の背景・ドット絵）を主役にする。

## 文言のルール

- 見出しは名詞だけ（「配合」「施設」）。「〜をお願いする」は使わない（「配合する」「建設する」）。
- 日付は1か所に1回。1週分なら「A 〜 A」にしない。
- 台詞は1〜2文。ルールや数値の説明を入れない。モーグリは「〜クポ」。
- 開発中の言葉（従来どおり、新しい進行、参考、走行記録の形式など）を画面に出さない。
- 計算式・配点などの仕様は、必要なら折りたたみ（例：年度表彰の「配点」）に入れる。
- 「まだありません」は一覧が空のときだけ。

## 画面ごとの改善案（未実施）

### 週送り・報告

- 何もない週はモーダルを出さず、収支などを短く表示するだけにする。
- 通常のレースは結果の一覧だけ（観戦は任意）。GⅠなど重要なレースだけ、結果の前に「観戦する／結果だけ見る」を選ぶ。飛ばせない演出にするならGⅠ・ダービー級に限る。
- 誕生報告は厳選のための画面として作る。素質の結果を一番上に並べ、色で良し悪しが一目でわかるようにする。報告を開いたままでも1〜5キーでロードできるようにする（今はダイアログ表示中は無効）。
- 命名（2歳登録）は単独の画面にし、名付ける子の絵を出す。
- 4週まとめは「週｜出来事｜収支」の表にする。

### ホーム

- 牧場の絵（施設のイラストなど）の中に所有チョコボを表示する。
- 「今週」の欄に、出走予定・誕生までの週数・セールや配合の期間・療養中などを、該当するものだけ最大5行で出す。数値ダッシュボードには戻さない。
- 資金繰りが重要なので、所持金の横に今月の収支を出す。

### 配合（最優先）

- ①母 → ②父 → ③確認の3段階にし、実行ボタンは③だけに置く。
- 種牡羽は1行表示（小さな絵・名前・系統・得意な3つ・料金）。説明文は選んだ1羽の詳細にだけ出す。源流の説明文・距離と脚質・長所短所が同じ内容を3回書いているので1つにまとめる。
- 「母｜父｜子の予想」を1つの表に並べる。クロスはあるときだけ警告を出す。

### 個体詳細

- 役割ごとのタブにする（競走羽：能力｜予定｜戦績｜血統、幼羽：成長｜血統、繁殖羽：繁殖｜産駒｜血統）。
- 予定は8週分の横並びカレンダーにする。

### レース観戦

- 常に出す操作は再生・速度・スキップだけにし、残りは設定メニューへ。
- パドックは自分の羽を先に紹介し、他の羽は出馬表1枚で見せる。

### 見た目

- 本文15〜16px・最小12px、コントラスト4.5:1以上。明朝体は名前と見出しだけ。
- 評価記号（☆◎◯△X）を色付きの大きめのバッジにする。「X」は「×」に。
- ナビのアイコンを、ドット絵に合わせた絵に置き換える。

## 進め方

1. 文言の整理（実施済み。下記）
2. 構造：週送り（空の週・GⅠ・誕生・命名）、ホームの「今週」、配合の3段階、個体詳細のタブ
3. 見た目と演出：文字サイズ・コントラスト、アイコン、牧場の絵、GⅠのカットイン

## 実施済み：文言の整理（2026-10-04）

- 英字の飾り見出し（OUR LITTLE RANCH、RANCH LETTERS、INHERITANCE FORECAST など）、キャッチコピー、サイドバーの手紙、フッターを削除。ページ見出しは「チョコボ」「配合」「施設」「牧場手帳」「設定」。
- ホーム：見出し・コピー・下部の案内・常設のセール導線を削除。シロマの台詞を状態に合わせた1文にした（配合期間中の未配合、誕生までの週数、セール開催、療養中の羽）。期間中だけ「配合へ」「セールへ」を出す。スマホでは場面の高さを詰めた。
- 報告：英字見出し・差出人の定型句・切手・「SHIROMA」を削除し、日付はモーダルの見出しだけにした（1週分の週報は見出しも省略）。立ち絵が見える幅では差出人の行を出さない。週報の本文は結果の言い直しをやめて短い反応に。何もない週の定型文を短くし、誕生までの週数を出す。年度表彰は他牧場の受賞を台詞から外して一覧で表示。誕生報告から登録時期などの説明を削除。初勝利の「研究所を建設できる」は台詞から注記に分けた。
- 説明文の削除・短縮：能力ゲージ、誕生時の素質（凡例1行に）、子の予想、予定、方針、遺伝の座位・欠点、施設、セール、配合期間、種牡羽の検索、設定、売却・野生に返す確認。年度表彰の配点は折りたたみに。
- 開発中の言葉：「従来どおり抽選」→「ランダム」、「新しい進行のセーブデータ」→「データの書き出し／読み込み」、「地方交流参考」→「地方交流」、「2Dでレースを見る」→「観戦する」。古い走行記録の注記と、旧記録の血統補完の注記を削除。
- ボタン：「配合をお願いする」→「配合する」、「工事をお願いする」→「建設する／拡張する」、「この名前と方針で、モーグリに任せる」→「登録する」、「4週まとめて進める」→「4週進める」。方針は「着実に勝つ／重賞に挑む」。
- 重複：レース名と距離の二重表記（「1400m / 1400m」）、配合期間外の理由の二重表示、配合確認ダイアログでの子の予想・クロス表の再掲をやめた。
- 0件・無関係な表示を非表示：「重賞勝利はまだありません」、走っていない羽の戦績、重賞を勝っていない羽の重賞成績、産駒のいない競走羽の「配合相手・産駒」、施設の「ギルが足りません。」、療養0週。重賞歴が4件以上ならGⅠだけを並べる。
- キャラ：役割ラベル（「牧場のパートナー」「トレーナー」など）を削除。モーグリ名義の所感とレース後の感想をモーグリ口調に。ルールを説明する台詞を削除。
- 観戦：「RACE THEATER」と、画面上部のカメラ説明を削除。
