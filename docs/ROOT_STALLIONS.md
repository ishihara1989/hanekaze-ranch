# 源流32種類の命名と遺伝配分

2026-09-30。v4の配合画面・源流カタログに実装。データは `public/js/ranch-engine.js` の `ROOTS`。

## 原作の名前から取る方針

[チョコボスタリオン攻略・Lv1 カップリング](https://chocobo.qiqirn.com/lesson/03.html)で、通常28種・隠し込み32種と、エスプレッソプリン、カフェロワイヤル、チョコマカロン、プラリネ、トリュフ、ベジタブルなどの名前を確認した（2026-09-30参照、ファン攻略資料）。

洋菓子・カフェの飲み物を中心に、食材・パン・香辛料も混ぜる。短い単語名と「素材＋菓子」の複合名を併用し、カタカナで統一する。下記32名はこの命名傾向に沿った本作の新案で、原作に実在する源流名の一覧ではない。原作の能力値や血統効果は流用せず、本作の遺伝仕様に合わせる。

## 配分の原則

- 身体8能力、管理2資質、性格6要素の16項目に、主担当を2種類ずつ置く。32種類すべてに主担当・副担当を1つずつ設定し、副担当も各項目2種類。各項目には計4種類の選択肢がある。
- 短距離・持続型、短距離・末脚型、長距離・持続型、長距離・末脚型を8種類ずつ。同じ主担当の2種類は距離と出力配分が逆の傾向を持ち、得意能力を特定の脚質に閉じ込めない。
- 配合料金は全種600 G、年齢なし、常時利用可能。身体に強みを集中させる源流と、丈夫さ・回復・気性を補う源流を用意する。全種が同じレース成績になる調整や、初代から全能力が高い源流は置かない。
- 数値は研究所の公開段階に従う。配合一覧には持ち味の説明を載せ、身体・管理・性格は項目ごとに4種類へ絞り込める。路面・成長の長所でも絞り込める。

## 実際の遺伝データ

身体8能力と管理2資質は、既存の32座位・二倍体方式を使う。源流の遺伝品質は主担当100、副担当85、それ以外70。品質の計算は `50 + 1.25 × 有利アレル数`。対応する有利アレルは40本、28本、16本で、それぞれ20座位・14座位・8座位を有利ホモにする。非担当項目を初期集団の目安70より下げない。32源流全体で各品質項目の平均は72.8125。

同じ項目を主担当とする2源流は、有利座位の配置を16座位ずらす。これにより主担当2種だけでも、その項目の全32座位に有利アレルが存在する。さらに全源流を合わせた各座位について、2種類以上の供給元があることをテストする。名前だけ長所にして、必要な遺伝子がどの源流にもない状態を防ぐ。

性格の生得値は主担当112、副担当98、それ以外80。既存の「父母の生得値の平均＋±7」の継承を使い、調教・放牧で学習した性格は直接遺伝させない。走る意欲・賢さ・闘争心は高いほど常に有利という意味ではなく、他の性格や運用との組み合わせで持ち味になる。

距離軸Dは±0.85、出力配分Rは持続側−0.65／−0.7・末脚側+0.7。これは身体能力生成時の構成差で、距離ラベルを速度倍率として掛けない。身体の潜在能力は遺伝品質・D/R・既存の個体差から決まるので、「主担当100」は表示される最高速などが必ず100になるという意味ではない。

源流の遺伝子・性格・潜在能力はカタログ用の固定シードで決まり、牧場の開始シードや再読込で再抽選しない。子どもの遺伝は従来どおり父母それぞれから1アレルを取る。

## 遺伝とレース効果の範囲

網羅対象は、身体・管理・性格とD/Rに加え、芝・ダート、低・高クッション、早い成長・遅い衰え始め・緩やかな衰え。芝とダートは各16種、低・高クッションも各16種、路面×クッションの4組は各8種に割り振った。成長の3特性には各8種の供給元を置き、残り8種は標準とした。得意適性は1、反対側は0.25。成長の得意因子は1、その他は0.5。いずれも固定した二倍体の因子対から片方を継承する。

体羽の基本7因子と全10表現色、額羽6色を32種に含める。マロンパルフェが金因子を1つ持つ。金因子は画面の研究情報や絞り込みでは公開しない。顕性順位、金因子2つの出生不成立、接地効率への効果、成長曲線の式は[遺伝拡張の仕様](GENETICS.md)に記載。坂への独立した適性遺伝子は設けていない。

羽混み耐性・闘争心は保存・継承されるが、現行の単独走ベースのレース計算にはまだ接続されていない。今回も遺伝素材としての配分までとし、集団の進路選択や競り合いが実装された際に役割を検証する。全16項目が現在のレースですべて有利に作用する、という検証結果ではない。

## 選択画面

「源流」「他の牧場」「始祖」「自家牧場」の4タブ。始祖は所有者より優先して始祖タブへ分類する。各タブの候補数と空欄の理由を表示し、空タブでは配合を無効にする。タブを切り替えたときに、隠れた前の候補のまま配合しない。各タブ内の直前の選択を保持し、左右キー・Home・Endでも切り替えられる。

## 保存データと系統

v4保存キーは変更しない。読込・バックアップ復元時に旧4源流を同じ個体ID・`root-0`〜`root-3`のまま新カタログへ更新し、残り28源流を追加する。源流自体の名前・能力は新配分になる。既に生まれた所有羽の遺伝子・能力・調教・血統参照、所持金・週・報告・乱数列は維持する。妊娠中の父IDも維持し、出生時は更新後の源流の遺伝子を参照する。

更新は `rootCatalogVersion` で一度だけ行う。今回の遺伝拡張ではバージョン2に更新する。既存の所有羽には中立の適性・衰え因子、以前の成長型に対応する成熟因子、現在の体羽色を保つ因子を補完する。既存の身体の潜在能力は維持し、現在能力は新しい成長曲線で計算する。始祖入りは32系統すべてに対応し、同系統の先代の置換規則と所有種牡羽の羽房枠を維持する。

## 検証

`npm test` で、全項目の主副担当数、全座位の供給、32種の実際の継承、固定カタログ、旧v4読込、最後の系統の始祖入り、タブ分離・空欄・配合先・絞り込み・キー操作を検証する。遺伝拡張は `tests/genetics.test.cjs` で色の全組み合わせ、金因子、独立した成長効果、適性によるレースの有利不利も確認する。

[序盤96通りの結果](gamebalance/OPENING_VALIDATION.md)は、セール3羽×源流32種を150週進めた固定シードの確認。全通りで出走・完走・資金維持、94通りで初勝利、2通りは150週時点で未勝利。最低資金13,107 G。全組み合わせの同期間内の初勝利は保証せず、各セール牝羽に勝利へ届く組み合わせがあることを確認する。多世代での強さや特定源流への偏りの調整は今後の課題。
