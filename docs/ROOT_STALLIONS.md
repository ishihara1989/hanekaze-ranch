# 源流32種類の命名と遺伝配分

2026-10-03更新。v4の配合画面・源流カタログに実装。基本プロフィールは `public/js/ranch-engine.js` の `ROOTS`、適性の因子対は `public/js/ranch-genetics.js` の `source()`。

## 原作の名前から取る方針

[チョコボスタリオン攻略・Lv1 カップリング](https://chocobo.qiqirn.com/lesson/03.html)で、通常28種・隠し込み32種と、エスプレッソプリン、カフェロワイヤル、チョコマカロン、プラリネ、トリュフ、ベジタブルなどの名前を確認した（2026-09-30参照、ファン攻略資料）。

洋菓子・カフェの飲み物を中心に、食材・パン・香辛料も混ぜる。短い単語名と「素材＋菓子」の複合名を併用し、カタカナで統一する。下記32名はこの命名傾向に沿った本作の新案で、原作に実在する源流名の一覧ではない。原作の能力値や血統効果は流用せず、本作の遺伝仕様に合わせる。

## 配分の原則

- 身体8能力、管理2資質、性格6要素の16項目に、主担当を2種類ずつ置く。32種類すべてに主担当・副担当を1つずつ設定し、副担当も各項目2種類。各項目には計4種類の選択肢がある。
- 短距離・持続型、短距離・末脚型、長距離・持続型、長距離・末脚型を8種類ずつ。同じ主担当の2種類は距離と出力配分が逆の傾向を持ち、得意能力を特定の脚質に閉じ込めない。
- 配合料金は全種600 G、年齢なし、常時利用可能。身体に強みを集中させる源流と、丈夫さ・回復・気性を補う源流を用意する。全種が同じレース成績になる調整や、初代から全能力が高い源流は置かない。
- 数値は研究所の公開段階に従う。配合一覧には持ち味の説明を載せ、身体・管理・性格は項目ごとに4種類へ絞り込める。路面・成長の長所でも絞り込める。

## 実際の遺伝データ

身体8能力と管理2資質は、既存の32座位・二倍体方式を使う。源流の遺伝品質は主担当100、副担当85、それ以外70。品質の計算は `50 + 1.25 × 有利アレル数`。対応する有利アレルは40本、28本、16本で、それぞれ20座位・14座位・8座位を有利ホモにする。有利因子だけでの非担当品質は初期集団の目安70を維持する。潜性欠点の発現は別途、能力の表現値を下げる。32源流全体で各品質項目の平均は72.8125。

同じ項目を主担当とする2源流は、有利座位の配置を16座位ずらす。これにより主担当2種だけでも、その項目の全32座位に有利アレルが存在する。さらに全源流を合わせた各座位について、2種類以上の供給元があることをテストする。名前だけ長所にして、必要な遺伝子がどの源流にもない状態を防ぐ。

性格の因子は主担当112、副担当98、それ以外80。父母それぞれの因子対から片方ずつを継承し、その平均＋±7で生得値を求める。身体・管理・性格には[潜性の欠点](INBREEDING.md)による低下が別途かかる。調教・放牧で学習した性格は直接遺伝させない。走る意欲・賢さ・闘争心は高いほど常に有利という意味ではなく、他の性格や運用との組み合わせで持ち味になる。

距離軸Dは±0.85、出力配分Rは持続側−0.65／−0.7・末脚側+0.7。これは身体能力生成時の構成差で、距離ラベルを速度倍率として掛けない。身体の潜在能力は遺伝品質・D/R・既存の個体差から決まるので、「主担当100」は表示される最高速などが必ず100になるという意味ではない。

源流の遺伝子・性格・潜在能力はカタログ用の固定シードで決まり、牧場の開始シードや再読込で再抽選しない。子どもの遺伝は従来どおり父母それぞれから1アレルを取る。

## 遺伝とレース効果の範囲

網羅対象は、身体・管理・性格とD/Rに加え、芝・ダート、低・高クッション、右回り・左回り・直線、早い成長・遅い衰え始め・緩やかな衰え。芝とダートは各16種、低・高クッションも各16種、路面×クッションの4組は各8種に割り振った。成長の3特性には各8種の供給元を置き、残り8種は標準とした。路面・クッションの得意適性は1、反対側は0.25。成長の得意因子は1、その他は0.5。いずれも固定した二倍体の因子対から片方を継承する。

体羽の基本7因子と全10表現色、額羽6色を32種に含める。マロンパルフェが金因子を1つ持つ。金因子は研究所＋記念館または銅像で公開し、絞り込みには使わない。顕性順位、金因子2つの出生不成立、接地効率への効果、成長曲線の式は[遺伝拡張の仕様](GENETICS.md)に記載。坂への独立した適性遺伝子は設けていない。

羽混み耐性・闘争心は現在の集団レースにも接続済み。性格の作用と消耗の交換条件は [RACE_SYSTEM.md](RACE_SYSTEM.md) を参照。

## コーナー・直線の配分

右回り・左回りを独立した適性とし、各8種が得意、20種が普通、4種が苦手。得意を長距離、走行効率、賢さ、自制心の血統へ寄せた。両回りが得意なのはメープルブレッド、アールグレイ、バニラカスタード、セサミチュイルの4種。苦手は速度や出力、意欲、競争心が先に立つ6血統に置き、うちスパイスショコラとペッパークラッカーは両回りが苦手とした。性格そのものによる減速を重ねず、この得手不得手を独立して継承する。

直線は24種が普通、8種が得意で、苦手因子を置かない。得意8種のうち7種が短距離寄り、5種が末脚型。長距離・末脚型のフランボワーズにも直線の伸びを持たせ、長距離型でも直線の得意を育てられるようにした。三適性をすべて得意にした源流は置かない。

## 選択画面

「源流」「他の牧場」「始祖」「自家牧場」の4タブ。始祖は所有者より優先して始祖タブへ分類する。各タブの候補数と空欄の理由を表示し、空タブでは配合を無効にする。タブを切り替えたときに、隠れた前の候補のまま配合しない。各タブ内の直前の選択を保持し、左右キー・Home・Endでも切り替えられる。

## 保存データと系統

v4保存キーは変更しない。読込・バックアップ復元時に旧4源流を同じ個体ID・`root-0`〜`root-3`のまま新カタログへ更新し、残り28源流を追加する。源流自体の名前・能力は新配分になる。既に生まれた所有羽の遺伝子・能力・調教・血統参照、所持金・週・報告・乱数列は維持する。妊娠中の父IDも維持し、出生時は更新後の源流の遺伝子を参照する。

更新は `rootCatalogVersion` で一度だけ行う。コーナー・直線の追加ではバージョン4に更新する。既存の非源流羽には未保存の3適性を普通として補完し、記録済みの因子と孵化結果は保持する。既存の所有羽には中立の適性・衰え因子、以前の成長型に対応する成熟因子、現在の体羽色を保つ因子を補完する。既存の身体の潜在能力は維持し、現在能力は新しい成長曲線で計算する。始祖入りは32系統すべてに対応し、同系統の先代の置換規則と所有種牡羽の羽房枠を維持する。

## 検証

`npm test` で、全項目の主副担当数、全座位の供給、32種の実際の継承、固定カタログ、旧v4読込、最後の系統の始祖入り、タブ分離・空欄・配合先・絞り込み・キー操作を検証する。遺伝拡張は `tests/genetics.test.cjs` で色の全組み合わせ、金因子、独立した成長効果、適性によるレースの有利不利も確認する。`tests/course-aptitude.test.cjs` でコーナー・直線の配分、独立継承、左右による有利不利、出口ボーナス、旧記録の保持も確認する。

[初期配合の勝利経路検証](gamebalance/OPENING_VALIDATION.md)は、セール3羽×源流32種から禁止配合3通りを除いた93通りについて、実際に産駒を生成し、成熟時に潜在能力の90%を仮想的に発揮する状態で新羽・未勝利の芝・ダート計4競走を走らせる固定シードの確認。93通りすべてに一般参加だけの組を勝てる経路がある。性格の追加学習は仮定せず、外枠から実物理で判定する。150週内の初勝利や実際の育成期間・資金維持はこの監査の対象外。多世代での強さや特定源流への偏りの調整は今後の課題。
