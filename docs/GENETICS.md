## 1. 芝・ダートとクッション

芝、ダート、低クッション、高クッションの4適性を独立した遺伝子対として保存する。父母からそれぞれ1つの値を継承し、2値の平均が適性になる。内部0〜1、公開後の評価尺度は50〜150。研究所では5段階、記念施設で遺伝の数値と座位を表示する。両路面や両クッションに強い子も配合できる。筋・代謝構成D／出力配分Rとは別の要素で、能力の潜在値を書き換えない。

クッション値の方向は [JRAの説明](https://www.jra.go.jp/keiba/baba/cushion/)に合わせ、「高い＝硬め・反発力が高い」「低い＝柔らかめ」。ただし本作の0〜1はゲーム用に正規化した指標であり、JRAの実測値ではない。ダートへの適用・以下の係数も本作の調整値。

| コース | 路面 | 良羽場でのクッション指標 |
|---|---|---:|
| 天空神殿 | 芝 | 0.75 |
| 王宮都市 | ダート | 0.60 |
| 熱帯密林 | 芝 | 0.35 |
| 砂浜公園 | ダート | 0.15 |
| 秘境遺跡 | 芝 | 0.50 |
| 山岳廃坑 | ダート | 0.80 |

羽場状態を良=0、稍重=1、重=2、不良=3として、芝は1段階ごとに−0.12、ダートは湿って締まるモデルとして+0.08。結果を0〜1に収める。0.4未満は低、0.6超は高、それ以外は中と表示する。現行カレンダーは従来どおり良／重を生成し、計算器は4状態すべてに対応する。新しい天候シミュレーションは今回追加しない。

路面に合う適性をS、クッション指標をcとして、クッション側の適合度Cを補間する。

```text
C = (1-c) × 低クッション適性 + c × 高クッション適性
η = 羽場の基礎効率 × (1 − 0.08 × (1-S)) × (1 − 0.08 × (1-C))
```

基礎効率は芝が `0.975 − 0.008×羽場段階`。ダートは良0.95、稍重・重0.965、不良0.935。いずれもゲーム用初期係数。適性が高いほど接地時の損失を減らせる。

`race-physics.js` の `step` に接地効率ηを渡す。最大推進力をη倍にし、地面で同じ力を得るための筋出力を1/η倍で計算する。脚の負荷も接地損失を含む筋力で計算する。そのため、発走・再加速・坂での押し出しと、巡航・スパートの消耗に効く。生まれ持った最高速度上限や心肺の最大供給量は変更しない。巡航目標は、元の有酸素供給量で損失を支払える速度から求め直す。

従来の実験ラボはη=1で動作し、既存の距離適性実験を変更しない。全疲労時の最低歩行力も維持する。モーグリの出走先選びには適合度を加味し、結果にはコース・羽場・クッションを保存する。予定と結果画面で条件を確認できる。

### 右回り・左回り・直線

`aptitude.rightTurn`、`leftTurn`、`straight` に各1座位の因子対を追加した。路面・クッション、距離軸D、出力配分R、性格とは独立して、父母から1因子ずつ継承する。右回り・左回りは0〜1（普通0.5）、直線は0.5〜1（普通0.5、苦手なし）。因子対の平均が走行に作用し、研究所で評価、記念施設で数値と座位を公開する。コース適性の5段階評価は50=X、75=△、100=◯（普通）、125=◎、150=☆で、直線にはX・△が現れない。配合予測・クロスの有利変異・孵化結果にも同じ評価で接続する。

コーナーではコースの回転方向に対応する適性Aを使い、目標速度を `1 − (0.10 − 0.08×A)×きつさ` 倍とする。きつさは `160 / 走行レーンの半径(m)` を0.65〜1.35に収める。半径160mなら、苦手10%、普通6%、得意2%の目標速度低下。得意でも減速が残る。コーナーの余計な筋仕事は `1 + 0.04×(1−A)` 倍で、同速度なら得意ほど消費を抑える。速度は既存の加減速・出力・疲労の制約に従う。

直線ではS=`2×(直線適性−0.5)` として、目標速度・最高速度上限を `1+0.02×S` 倍する（最大+2%）。実際に通過したコーナーの出口から60mの間、最大推進力へ `1+0.04×S×(1−出口からの距離/60)` 倍の補正を掛ける。出口直後の最大+4%から滑らかに消える。発走位置が出口付近だっただけでは推進力ボーナスを付けない。両直線・複数周回で同じ規則を使い、コーナー中は直線ボーナスを付けない。

補正で身体能力の潜在値、有酸素の最大供給量、無酸素容量を増やさない。余分な速度や推進力の仕事は通常どおり支払い、出力不足・疲労・前詰まりの制約を受ける。単独走の実験ラボには追加せず、実際の牧場レースへ適用する。

無親生成の直線因子は普通を7/8、得意を1/8の確率で各因子に配分する。約76.6%が普通の因子対、約23.4%に部分的または完全な直線の長所があり、苦手は生まれない。右回り・左回りは各因子で普通6/8、苦手1/8、得意1/8。源流はこの抽選を使わず、固定配分とする。

## 2. 羽色と額羽

通常羽色は父母それぞれの2因子から1つずつ受け継ぐ。順位は依頼内容の指定を採用する。

```text
黒 ＞ 白 ＞ 緑＝ピンク ＞ 赤＝青 ＞ 黄
緑＋ピンク → 灰
赤＋青 → 紫
```

灰・紫という独立因子は作らず、混色を生む元の2因子を次代に渡す。例えば紫同士の配合では、通常因子は赤：紫：青=1：2：1になる。別順位の組み合わせでは顕性側が発現する。

[原作の羽色遺伝資料](https://w.atwiki.jp/chocosta/pages/47.html)は「白＞黒」で、稀な順位逆転と通常色と同じ座位の金因子を記載している。本作は明示された「黒＞白」を優先し、順位逆転は導入しない。金は次項の独立した顕性因子に変更する。

額羽は黄・赤・青・白・黒・虹。父の額羽または母の額羽を等確率で継承し、混色・顕性順位は設けない。身体の色とは独立する。通常表示は羽色10色、額羽6色に対応し、虹はSVGのグラデーションで描く。

## 3. 隠し金因子

通常色の2因子とは別に、金因子G／通常因子gを持つ。金は通常色を覆って発現するが、通常色の遺伝子は保持して次代に渡す。

| 遺伝子型 | 発現・出生 |
|---|---|
| gg | 通常の羽色 |
| Gg / gG | 金羽。次代へのG継承確率は1/2 |
| GG | 出生しない |

Gg×ggは約1/2が金羽、Gg×Ggは1/4が出生不成立、1/2が金羽、1/4が通常色。生まれた子だけに限ると約2/3が金羽になる。GGの結果を健康な子に引き直さない。

金因子を継承しなかった子には、出生判定時に1/2000で片方の因子が新たにGになる可能性を設ける。この確率はゲーム用の設定で、現実の突然変異率ではない。判定は出生処理の一度だけ。保存した乱数列から復元でき、表示・再読込時に再抽選しない。既存の金羽や源流の金羽もすべてGgとして扱う。

金の元になる源流はマロンパルフェ（Gg）。新規セール・一般種牡羽の無親生成にはGをランダム配布せず、源流からの配合または子世代の突然変異で広がる。研究所と記念館または銅像が揃うと、他の座位と同様に金因子も表示する。突然変異率は表示しない。

GGでは4週後に卵がかえらなかった報告を出す。子羽は作成せず、予約羽房を解放する。その年の配合済み状態と配合料は維持し、母羽に新しい病気や能力低下は加えない。報告後も週を進め、翌年の配合へ進める。

実際の白毛では、KITの複数の変異が顕性遺伝し、W5・W10・W13・W22のホモ接合は胚致死と考えられる一方、W20は異なる。[UC Davis VGL](https://vgl.ucdavis.edu/test/dominant-white-horse)を参照し、今回はユーザーが選んだ「2因子では出生しない」型を単純化して採用した。白く見える馬すべてを同一の遺伝として扱う再現ではない。

## 4. 独立した3つの成長因子

各要素を独立した2因子の平均0〜1で表す。高いほど各長所が強く、片方の長所を上げても別の長所は下げない。

| 因子 | 内部キー | 0のとき | 1のとき |
|---|---|---|---|
| 早い成長 | earlyGrowth | 4.5歳で成熟 | 2.5歳で成熟 |
| 遅い衰え始め | lateDecline | 5.5歳から低下 | 8.5歳から低下 |
| 緩やかな衰え | slowDecline | 年10%低下 | 年2%低下 |

中間値は線形補間。年の低下率は能力の50を超える部分に対する係数の減少で、複利の減衰ではない。低下係数の下限は0.6。

```text
成熟係数 = min(実年齢 / 成熟年齢, 1)
加齢係数 = max(0.6, 1 − max(0, 実年齢−低下開始年齢) × 年低下率)
現在能力 = 50 + (潜在能力−50) × 成熟係数 × 加齢係数 × 調教係数
```

レースの参加年齢は従来の1月一斉加齢を維持し、身体成長は出生週を使った連続的な実年齢で計算する。幼羽から競走羽に登録しただけで能力が飛び上がらない。10歳の競走引退・20歳の通常繁殖引退は維持する。源流と始祖には加齢低下を掛けない。

研究所建設で適性・3成長因子・羽色の概要を公開する。記念館または銅像で成熟年齢・衰え開始年齢・年低下率と全座位を公開する。現在ステータスの数値は記念館と銅像の両方で公開する。1歳以下の成長3因子の5段階評価は施設なしで見える。

配合結果の予想は、施設なしでは身体・管理・性格の遺伝効果を5段階の範囲で表示する。研究所建設で7適性と3成長因子の予想を追加し、記念館または銅像で全予想項目の数値範囲も表示する。父母からの継承とクロスによる追加変異を含む最小〜最大で、誕生時の個体差と育成は含めない。予想の表示は乱数やセーブ内容を変更しない。

孵化報告には、各項目を「結果 / 可能範囲」（例：`◯ / △～◎`）で表示する。施設なしでは身体・管理・性格、研究所建設で7適性と3成長因子を追加する。研究所と記念館または銅像が揃うと「数値 / 最小～最大」も表示し、両方の記念施設が揃うと下限0%・上限100%で範囲内の位置を表示する。この位置は確率や百分位ではなく、遺伝効果の最小〜最大に対する線形の位置。最小と最大が等しい項目は「固定（抽選幅なし）」とする。

結果の記号だけを範囲内の位置で色分けする。90%以上（上位10%）は虹色、70%以上90%未満は青、30%未満は赤、それ以外は通常色。丸める前の実数値で判定する。結果の種類が少ない羽場適性・成長因子は最高値だけ青、最低値だけ赤、中間は通常色とし、虹色にはしない。抽選幅が0の項目は種類や評価に関係なく通常色。色は各項目が公開された段階から表示し、可能範囲の記号や数値には付けない。報告と牧場手帳の便りで同じ表示を使う。

範囲は孵化直前の父母から計算し、クロス変異と潜性の欠点による効果を含む。実際の結果には誕生時の個体差や育成を含めず、既存の遺伝評価と同じ尺度を使う。全26項目の結果・最小・最大を孵化報告と手帳の便りに保存し、あとから父母や源流が変わっても計算し直さない。閲覧時点の研究段階で表示項目を決めるため、施設完成後に過去の結果も詳しく読める。比較表追加前の報告には比較表を表示しない。コーナー・直線追加前の23項目の報告も保持し、未記録の3項目は表示しない。表示による乱数の消費や再抽選はない。

## 5. クロスと潜性の欠点

血量に応じた長所・欠点の追加変異、虚弱体質・気性難を含む潜性の欠点、他牧場の多世代配合は[配合拡張](INBREEDING.md)を参照。身体・管理・性格はaaの座数に応じて段階的に低下する。羽色・金因子はこのクロス変異の対象にしない。

## 6. 保存と検証

v4保存キーを維持し、`geneticsVersion=2`、`breedingVersion=1`、源流カタログ版4へ自動更新する。既存の所有羽はID・血統・潜在能力・身体の遺伝品質・調教・性格・羽色を保持。未保存だった羽場適性は各0.5、成長速度は旧成長型から、衰え開始と低下率は従来相当の7歳／年6%へ補完する。新設の額羽は黄。通常色の潜因子は当時未保存だったため、現色を発現する最小の組み合わせで補完する。金羽はGgにする。現在能力は新しい連続年齢モデルで再計算する。版1の羽場・成長・色因子はそのまま保持し、未保存の右回り・左回り・直線だけ普通の `[0.5,0.5]` に補完する。

既存源流は同じIDで新版配分へ更新する。妊娠中の父IDも維持し、出生時点の父母因子を使用する。カタログ更新は牧場の乱数を消費しない。新形式では異常な因子・身体色との矛盾・生存羽のGGを読み込まない。

`npm run test:ranch`、`node --test tests/*.test.cjs`。全通常羽色の49組、混色の継承、金の分離比と突然変異、出生不成立時の費用・羽房・報告・復元、成長3因子の独立性、適性による推進力とレース結果、32源流の網羅性、旧v4補完、UIの公開段階を検証する。

係数は初期調整値で、実馬の速度や繁殖リスクを予測するためのモデルではない。世代を重ねた適性・寿命因子の強さは継続調整する。
