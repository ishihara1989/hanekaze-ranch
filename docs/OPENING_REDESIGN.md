2026-09-30。今回の実装を記録する。数値は初期調整値で、将来の変更を制限しない。

## 体験の中心

ホームは「今週の牧場」。未読の報告があればシロマの報告を全面に表示する。読む前に次の週へ進まない。閉じると牧場風景と次の一手に戻る。主操作は「次の週へ」。4週送りは通常の週報を自動確認するが、月報・誕生・年次処理・登録・初記録で停止する。

常設の数値ダッシュボードを外した。所持ギルと日付だけをヘッダーに置き、チョコボ・配合・施設・牧場手帳に情報を分ける。手帳に予定、収支、記録・表彰、過去のシロマの報告がある。スマートフォンでは下部ナビゲーションになる。

## 最初の流れ

1. 1年3月第1週、20,000 G、所有0羽。シロマからセールへ案内。
2. 2〜3月の繁殖牝羽セールで1羽を購入。3候補、2,800〜3,200 G。確認画面に購入後の資金を表示。
3. 繁殖牝羽と種牡羽のリストから配合。源流は600 G、自家製は無料。料金と出産日を確認して実行。
4. 妊娠はゲーム上の仮定として4週。配合は1羽につき年1回。子ども用の羽房を予約する。
5. 誕生するとシロマの会話。初期放牧地は穏やかな平原。変更しなくても育つ。
6. 年齢は暦年制。出生年を0歳として1月第1週に加齢。この初年度の子は3年1月に2歳になる。
7. 2歳登録の報告内で名前と方針を確認。初期の名前・着実方針のまま「モーグリに任せる」だけでも進む。
8. モーグリが調教・休養・出走を自動決定。勝つことは保証しない。結果と賞金は週報で確認できる。

年齢は旧版の経過週方式と異なる。古いセーブは読み込まず、`hanekaze-ranch-v4` に独立保存する。古い保存キーを移行・削除しない。

## 会話と情報公開

シロマは購入・初配合・誕生・初勝利・初GⅠ・初ダービー・特別記録・年末の始祖オファーで会話する。初記録はキーを保存し、再読込で再発火しない。週報・月報・年報もシロマの台詞。表情は既存の8枚を利用。トレーナー用にモーグリの透過画像を追加。

詳細はデビュー前ならシロマ、登録後ならモーグリの所感を先に表示する。

| 研究所の公開段階 | 明示的に詳細を開くと見える情報 |
|---|---|
| 未建設 | 1歳以下は成長率、2歳以上は現在ステータス。繁殖担当はステータス遺伝の合算だけを表示。すべて5段階評価 |
| 研究所 | ステータス以外の遺伝、得意羽場などの詳細な競走情報 |
| 研究所＋記念館または銅像 | 全遺伝の数値・座位情報（通常羽色・金因子・潜性の欠点を含む） |
| 研究所＋記念館＋銅像 | 全情報。現在能力の数値、成熟時の伸びしろ、競走羽の管理数値 |

研究所はレース初勝利で建設解放。研究所の拡張は行わず、建設と銅像・記念館の組合せで4段階に公開する。1歳以下の成長率は、早い成長・遅い衰え始め・緩やかな衰えの評価。[評価境界と合算方法](ECONOMY_PROGRESSION.md#能力の公開と実績遺伝)を参照。

## バランス資料との接続

`docs/gamebalance/ATTRIBUTE_MAPPING.md` の能力体系と `trait-mapping.js` の物理変換を採用。旧30能力の数値を拡大して流用しない。

- 身体8能力と管理資質の品質は32座位の二倍体遺伝子。父母から1つずつ継承。品質 `50 + 1.25 × 有利アレル数`。
- D/Rは父母の体質因子を継ぐ。潜在能力は出生時にσ10の切断正規分布で一度抽選し、その後は再抽選しない。
- 現在能力は成熟・調教状態・高齢による低下から計算。潜在能力を超えない。調教結果や学習した性格を子に直接遺伝させない。
- 平原は自制・賢さ・根性、森は意欲・羽混みへの慣れ・闘争心に寄せる。森で知能を下げたり、平原で根性を下げたりしない。
- レースは共通の出力・エネルギー・脚疲労モデル。12羽を同じ時刻で進め、性格は隊列に応じた目標速度・余力の使い方・余計な消耗に作用する。距離適性による速度倍率なし。詳しくは[集団レース](RACE_SYSTEM.md)。
- 出走後の体力と脚負担は消費エネルギー・無酸素使用・脚疲労から計算。GⅠラベルで消耗を増やさない。
- 自動出走は原則4週以上の間隔、体力75以上・脚負担25未満・疾病なし。着実方針は重賞へ慎重、挑戦方針は出走可能な重賞を優先。

身体変換の既存実験に加え、旧版では序盤150週の通し検証を実施。現行の[初期配合の勝利経路検証](gamebalance/OPENING_VALIDATION.md)は、産駒の潜在能力の90%を仮想的に発揮する状態で新羽・未勝利を走らせる方式に変更している。多世代のGⅠ難易度の最終調整は今後行う。

## 経営と長期要素

| 項目 | 実装 |
|---|---|
| 源流 | [32系統](ROOT_STALLIONS.md)、無年齢、常時利用可能。16項目に主担当2種・副担当2種 |
| 一般種牡羽 | 毎年2羽追加、引退年から5年間掲載。実績・ファンで料金算定 |
| 自家製種牡羽 | 自家配合無料。GⅠ勝者に月末の外部依頼、配合料収入 |
| 始祖 | GⅠ勝利産駒3羽以上、計7勝以上で年末にオファー。無年齢。同系統の先代は置換。源流32系統に対応し、所有種牡羽の羽房枠を使用 |
| 羽房 | 4段階。幼羽・競走羽8→16→24→32、種牡羽・繁殖牝羽各4→8→12→16 |
| 坂路・プール・コース | 瞬発系・心肺・総合の調教効果向上 |
| 温泉・診療所 | 休養時の回復、傷病期間の短縮 |
| 放牧地 | 穏やかな平原（初期建設済み）、過酷な森 |
| グッズ | GⅠ勝者のファンに比例。引退後5年で0、殿堂入りは10%を維持 |
| 銅像 | 同じ年の三冠・牝羽三冠で解放 |
| 記念館 | 牧場通算の8大競走勝利で解放 |
| 年度表彰 | 最優秀2歳・3歳・古羽・牝羽・年度代表羽。牧場内の当年実績で選出 |

GⅠ出走でファン150、勝利で1,200。三冠など同一年の組合せ、GⅠ3/5/7/9勝、牝羽の混合GⅠ勝利、黄金のGⅠ勝者で追加ボーナス。難易度は追加ボーナスの1.5 / 1 / 0.7倍。豪脚一閃・逃げ切りは12羽の走行軌跡から判定。殿堂入りはGⅠ3勝以上で競走引退時に認定する仮設定。

維持費不足は未払金となり、月末に所持金から返す。強制処分はしない。購入・配合・工事は手持ちを超える支出を受け付けない。

## 保存と確認

リセットは「設定 → セーブをリセット」。破棄する項目と初期状態を示す独自ダイアログ。最初のフォーカスはキャンセル。Escape・閉じるでは状態不変、確定で即時保存。購入、配合、工事、競走引退、バックアップ読込にも確認を設ける。モーダルはフォーカストラップと背景のinertを設定。

不正・破損した保存は上書きしない。仮の牧場を表示して保護を通知し、明示リセットで復帰できる。別タブ更新は操作を止め、再読み込みを案内。localStorageが使えないときは書出しを案内する。

## 試作上の範囲・次の検証

- 旧版の競合牧場の永続シミュレーションと観戦アニメーションは新UIに未接続。対戦相手はレースごとの決定的生成、結果・着順・時計は保持。
- 根性・意欲・賢さ・自制心に加え、接近時の闘争心・羽混み耐性、賢さによる余計な消耗の抑制とリード時の温存を接続済み（[集団レース](RACE_SYSTEM.md)）。横方向の進路取り・接触・閉塞は未実装。路面・クッションの適性は接地効率へ接続済み（[遺伝拡張](GENETICS.md)）。
- 年度表彰は世界全体のランキングでなく牧場内実績による選出。一般種牡羽の経歴は生成値。外部配合依頼は収入イベントで、相手牧場の産駒は永続生成しない。
- 銅像・記念館は研究所の公開段階を補助。研究ポイントや研究期間は置かない。
- 受胎4週、年1配合、20歳繁殖引退、10歳競走引退、物価・表彰基準は仮設定。

## ファイルと検証

本体は `public/js/ranch-engine.js`、UIは `public/js/ranch-ui.js`、スタイルは `public/css/ranch.css`。`world.js` は暦と番組、`race-physics.js` と `trait-mapping.js` は身体モデルを提供する。

`node --test tests/*.test.cjs` で新進行・新UIと旧モデル・実験の回帰テストを実行。`node tools/audit-opening.cjs --write` で96通りの序盤結果を再生成。
